# Temperature reduction with an explicit C workspace

`runtime/native_temperature_reduce.c` now uses ordinary C accumulators, an explicit zeroed eight-byte calibration workspace and the caller's output pointer. All fixed-register declarations, empty inline assembly and native-stack-address helpers are removed. Fresh REA analysis of stock `0x51108` confirms the reduction sequence. The C interface retains the packed five-byte result, while live-register observations and aliases into the old private calibration/output-pointer frame are retired.

Bus acquire, pair enable, initial 80-tick delay, ten ordered channel-0/channel-2 reads with a five-tick delay after every pair, pair disable, bus release and calibration read remain in stock order. Status returns do not short-circuit the sequence. Both channels use wrapping unsigned accumulation, signed extrema with stock initial values, signed division toward zero after wrapping subtraction, and signed-16 narrowing. Calibration scans the first six bytes, handles signed offsets and modes 0/1, and preserves repeated log-mode reads and all six result/extrema log arguments. Output type byte 2 is written after the result halfwords.

All 36,720 paired stock/C cases pass (73,440 executions), also checked against an independent signed trimming/calibration oracle. Coverage includes signed boundaries, wrapped full-word sums, random samples, calibration modes and negative offsets, changing log modes, provider statuses and three output alignments. Checks compare output/guards, complete provider-call order, log text/arguments, zeroed calibration at provider entry, preserved R4-R11, SP and interrupt masks. Private frame size and active scratch registers are excluded. All bus/sensor/delay/calibration/log providers are modeled.

Four compiled defects fail runtime assertions: wrong trim divisor, unsigned minimum comparison, shortening the calibration scan and wrong per-sample delay. The ordinary source build changes only the reducer object; the other 730 R1 object hashes and the export/import sets are unchanged. `build/sources-goal-r1-temp-reduce-pure-c/report.json` compiles all 731 units and composes both payloads without failures or duplicate strong symbols. Application imports remain 157 and bootloader imports 34. `make sources-check` passes.

The unit had no optional exact-byte source-plan selection, so that plan is unchanged. The [earlier reducer review](temp-reduce-c-review.md) retains historical frame/alias evidence; that private-frame contract is superseded by this C workspace. [Machine-readable evidence](temp-reduce-pure-c-review.json) records fresh REA observations, build hashes, results, defects and audit. Probes and the positive subset ELF live under ignored `build/goal-r1-temp-reduce-pure-c/`.

Physical electrical behavior, sensor timing, arbitrary alias/fault/concurrency behavior, full calibration-provider integration and a complete firmware link remain unverified. This is a source-level C ABI migration, not a byte-identity claim.
