# R1 IQS IRQ processing in C

`r1/src/application/runtime/native_iqs_irq.c` implements ten stock entries: IRQ worker `0x30e6c`, register refresh/end/suspend helpers, word read/write adapters, model/count adapters, channel average and float event dispatch. Narrow state owners cover four control/recovery bytes, the signed raw-report selector, last position, and two three-halfword status records. Their compiled initializers match authenticated cold RW. The existing slider flag and callback-word owners are reused; final placement remains a linker gate.

The worker preserves the distinct exits. Initial control handling writes refresh/suspend configuration, clears its byte and ends communication. Status bit 7 resets/reconfigures and ends; ATI recovery also ends. The bit-12 “too many fingers” path writes register `0x33` byte `0x08`, logs the live snapshot and returns **without** a communication-end write. Normal processing reads 42 or 48 bytes, computes the binary32 mean of 21 or 24 unsigned halfwords, dispatches it through S0, optionally performs a cleared second read from `0xe1`–`0xe3`, then ends. A fresh signed-selector read decides whether to clear it to FF and queue raw data.

Float dispatch captures status flags before the tick call, preserves the native signed comparison of the average's raw bits against `0x43af0000`, reloads position/cache and callback afterward, and passes four integer words plus the unchanged float. A direct C union supplies the bit view. Tests include threshold neighbors, signed zero, infinities, NaNs and subnormal patterns, plus changed callback targets and state during the tick call. Both integer and callee-saved FP registers are checked; caller-saved FP registers are deliberately clobbered in modeled providers.

All 1,968 direct comparisons pass: 384 worker-policy cases, 1,024 selector cases, 104 float-callback cases, 40 adapter cases, 256 seeded live-state cases, 128 average-oracle cases and 32 retained/cleared partial-read cases. A further 612-case pass executes actual C IQS ports, touch transport and device registry against prepared controller callbacks. Both passes check twelve defined C fallback cases for unwritten private word/sample bytes. These zero-initialized buffers intentionally replace native private-stack garbage; equality to native uninitialized private bytes is not claimed. Public retained status buffers and cleared secondary buffers are compared to stock on partial reads.

Twelve compiled defects are rejected before final unmodified passes. REA receipts match the pinned firmware bytes. An earlier replay with an out-of-line memory-copy bit cast skipped a caller instruction under Unicorn; its diagnostic is retained under the probe directory. This is an emulator observation, not evidence of a physical memory-library fault. The final direct C bit view passes the raw native comparisons.

The normal build compiles 834 units (752 application, 82 bootloader), without duplicate strong symbols. The IRQ-worker import closes; hardware-variant detection, ATI recovery and reset/reconfiguration become explicit dependencies. Application imports rise from 75 to 77. All 831 prior non-generated objects are unchanged; two generated bootloader objects differ. R1 source validation passes (834 units, 620 sources). Global checking retains the unrelated G2 `resident_rom_thumb_set.S` manifest omission.

Primary probes model ports, variant/configuration, reset/recovery, ticks, transmit and logging. The deeper pass also executes the existing software transport/registry layers. FP replay starts with FPSCR zero. Physical I2C/touch behavior, timing, final linking and boot remain unverified. Byte identity is not required by the current user instruction.
