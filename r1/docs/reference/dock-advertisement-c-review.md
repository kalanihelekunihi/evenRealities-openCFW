# R1 dock advertisement mailbox sender in C

`st25/native_dock_advertisement.c` supplies stock `0x772a8`. It writes packet bytes 1–3 as `55 03` and the low switch-flag byte, then transmits exactly 23 bytes through the existing typed ST25 SDK provider. It selects success/failure strings from the full write result, reloads logging gates independently, and logs the original full-width switch flag. Bytes outside the three patched fields are retained, including byte 23 which is not transmitted. No new state owner, assembly or executable blob is added.

Stock saves incoming R1 as a meaningful second argument. The previous parser C boundary declared only the packet argument; this change corrects its declaration and passes the captured dock-phase byte explicitly. The phase is published as 0xaa only after sending, as before. The caller's allocated code changes only in the parser section; its other allocated sections, state and helpers are identical. The exact source delta and hashes are retained in the caller audit. This replaces reliance on an incidental scratch-register value with the explicit C ABI.

REA binds the sender's code, logger constants and strings to the locked image. Verification passes 1232 direct stock/C comparisons with the real stock/C SDK mailbox-write providers and prepared device IO objects. Cases vary full-width flags, zero and high-bit error statuses, every log-bit combination and changing gates, mutation of the transmitted packet by the backend, interrupt masks and poisoned stacks. Packet guards and all 24 caller bytes are checked. Both loggers retain the full original flag even after backend packet mutation. I2C and logging leaves remain modeled.

An additional 216 comparisons execute the actual stock/C dock parser, sender and SDK write provider together. Six phase values, both write outcomes, log gates and heartbeat counts verify the second-argument path and phase publication. Formatter, timer and other parser leaves remain modeled; actual formatting is separately covered by the preceding dock-policy receipt. Seven compiled defects are rejected: wrong command, wrong write size, truncating the logged flag, ignoring write failure, logging the mutated packet flag, wrong SDK log gate and dropping the parser phase argument. Normal direct and integration probes pass after mutation testing.

The open-toolchain build compiles 819 units (737 application, 82 bootloader), with 70 application imports and no new failures or duplicate strong symbols. The advertisement import closes and none are added. Among 818 prior units, 815 object hashes match; the parser object changes for its explicit argument and two generated boot objects differ with build paths. Only the parser source changes among previous inputs. No G2 source or qualification selection changes. Final application linking, startup placement, electrical transactions and device boot remain open.
