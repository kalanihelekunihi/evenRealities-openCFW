# RTC backend wrappers with the ordinary C ABI

`board/native_clock_port.c` no longer contains fixed-register declarations or empty inline assembly. The two backend wrappers still call the out-of-line RTC request functions and return 1 regardless of request status. Update forwards epoch and signed offset; bind forwards incoming R3 as the callback. Context/unused inputs remain ignored. Private frame layout and scratch-register results are no longer interface requirements.

Fresh REA analysis of `0x50daa` confirms callback forwarding and unconditional success. Raw locked stock execution also tests update at `0x50db6`. The normal product object passes 256 paired stock/C wrapper cases (512 executions) with full-width random arguments and four request statuses. Checks compare meaningful forwarded arguments and return values, preserved R4-R11, final SP and interrupt masks. Request callbacks clobber caller-saved registers. Four compiled defects fail runtime assertions: wrong success value, shifted epoch, lost callback and propagating update status.

The other three RTC request functions' instruction bytes and named relocations are unchanged in the normal build. The other 729 R1 object hashes, exports and imports are unchanged. `build/sources-goal-r1-clock-port-pure-c/report.json` compiles all 730 units and composes both payloads without failures or duplicate strong symbols. Application imports remain 163; bootloader imports remain 34. `make sources-check` passes.

The obsolete exact selections for the two wrappers (22 bytes) were removed from `tools/build/source-plan.json`. No replacement selections were invented. Scoped official GCC qualification compiles but admits no exact bodies under that profile. Every other source-plan unit/region remains unchanged, including the separately admitted callback-binding request. The [earlier exact-provider review](clock-provider-exact-review.md) describes the superseded wrapper frame contract.

The optional license-free hybrid comparison build succeeds in `build/hybrid-goal-r1-clock-port-pure-c/`. Its application retains stock SHA-256 `0e788d433ea50fd36edb8f21a9c18b6062211e4a36dbc5bd7695ea5827f3aa1a` using 4,359 source-built bytes, 641,801 pulled-through bytes and 248 resource bytes. This build uses fallback for the retired wrapper selections; it does not integrate the new ordinary C wrappers or prove source completeness. Source-built counts also include assembly elsewhere. Byte identity is optional comparison evidence, not the completion requirement.

[Machine-readable evidence](clock-port-pure-c-review.json) records provenance, normal/hybrid build hashes, qualification, retired selections and defect checks. Probes live under ignored `build/goal-r1-clock-port-pure-c/`. Requests are modeled in the wrapper fixture. Complete hardware request execution, physical RTC timing and a complete source firmware link remain unverified by this change.
