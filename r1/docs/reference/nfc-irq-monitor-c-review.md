# R1 NFC/charging IRQ storm limiter in C

`native_nfc_irq_monitor.c` supplies the registered callback at stock 0x42d40. It is an IRQ storm limiter, not an ADC sampling or periodic rescheduling routine. The normal open-toolchain build compiles 811 units (729 application, 82 bootloader). Its implementation closes `r1_nfc_charge_monitor_callback_00042d40`, reducing application imports from 73 to 72 with none added. R1 source checking and strict bootloader linking pass. Global checking retains the unrelated G2 unlisted `resident_rom_thumb_set.S` failure.

The callback obtains the current tick before reading the cursor, writes that tick into a seven-entry ring and advances the cursor modulo seven. It counts nonzero timestamps whose unsigned age is at most 0x2800 ticks. Zero is deliberately excluded, including at tick zero; unsigned subtraction preserves rollover behavior. The live cursor must be 0..6. Cold zero and modulo-seven updates maintain that domain in the C implementation; corrupt cursors are not normalized or admitted by this proof.

When all seven entries qualify, the callback suppresses notifications. It sets suppression to one and logs only on the initial transition; an already nonzero suppression byte is left unchanged. With fewer than seven qualifying entries it clears any suppression, logs that transition and always sends battery task flag 2. The callback does not schedule a timer. Log markers, format strings, count/limit arguments and live short-circuited mode gates match stock. The existing named-GPIO IRQ dispatcher discards callback return values, consistent with the void callback contract; private frames and incidental return registers are not outputs.

Only the accessed cursor byte (stock 0x20006872), suppression byte (0x20006873) and seven timestamp words (0x20016b54..0x20016b6f) have new owners. They do not replace the existing late-setup byte at 0x20006870, I2C5 state, YHM request at 0x20016b70 or battery thread handle. Decoded stock initialized RAM confirms zero cursor/suppression bytes. The timestamp object has explicit C zero initialization; full startup/BSS placement remains a final application gate.

Raw-stock/C execution passes 10752 boundary pairs, 1024 seeded pairs and 168 clock/log mutation pairs. An independent state oracle checks every updated ring, cursor, suppression state and notification decision. Cases cover every valid cursor, suppression bytes 0/1/2/255, tick zero and rollover, inclusive/exclusive window boundaries, future timestamps, zero sentinels, log bit combinations, changing log modes, masks and poisoned stacks. State write order/width and all formatter/SDK arguments are compared. Clock callbacks can replace the live cursor/ring before returning, while log callbacks can replace the battery thread handle before notification. The actual C battery flag wrapper and shared handle owner execute; clock/log/OS flag leaves are modeled.

Four integration sequences execute the actual late setup and YHM completion path, capture the installed monitor callback through registry operations, then invoke that captured word eight times. The first six events notify, the seventh suppresses, and a later timestamp clears suppression and resumes notification. The actual I2C5/YHM/registry setup and limiter code execute. Device leaves, chip configuration, delays and OS services are modeled; physical IRQ delivery and concurrency are not proved.

Eight compiled defects are rejected: exclusive window comparison, counting zero sentinels, early suppression, notifying while suppressed, missing suppression publication, failed recovery clear, wrong cursor modulus and wrong timestamp slot. The normal probe passes again after the mutants. REA's 388-byte window at 0x42d40 includes 218 code bytes, following literals and strings and matches the locked application.

The audit preserves 808 prior object hashes, including the late setup and existing I2C5/YHM/battery owners. Generated boot objects retain allocated bytes and normalized relocations. The only manifest change is the new unit; no source qualification plan or G2 source is modified. Chip configuration, acquisition and flag-dispatch children, manager topology, final application linking and device boot remain open.
