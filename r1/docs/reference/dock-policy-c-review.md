# R1 dock-frame policy, field-seen adapters and field-control callback in C

`st25/native_dock_policy.c` supplies dock policy `0x77430`, field-seen getter/setter `0x96a48/54` and field-control callback `0x32174`. New C owners correspond to the accessed dock bytes at `0x20006858/59/5a/5c/5d`, version storage at `0x20006864` and field-seen byte at `0x20006871`. Their cold values are 40, 0xaa, zero, zero, zero, `NULL` padded to 11 bytes, and zero, verified against authenticated decoded RAM. The configured byte at 0x685b, active driver pointer at 0x6860, late flag at 0x6870 and monitor cursor/suppression at 0x6872/73 keep their existing owners.

The policy ignores its length word as stock does. Frames beginning `55 03` log the advertisement subcommand; `55 04` log the field-control subcommand and schedule field-control callback argument zero at raw delay `0x800`. Other frames require bytes `01 02 03 04`. The input must be readable through byte eight and heartbeat output must expose 24 readable/writable bytes; these storage preconditions are separate from the ignored length argument.

A matching heartbeat increments the eight-bit counter with wraparound, decodes two big-endian halfwords, formats the first value's last three decimal digits and the second value as minimum-width four into the 11-byte version field, reloads frame byte eight as dock type and publishes field-seen one. It requires raw mailbox control `0x81`. The selected C SDK register API preserves the raw-byte requirement while using its typed context layout; read errors stop before consuming output. When phase is not 0xaa, advertisement sending is called and phase becomes 0xaa afterward, irrespective of its incidental return. That advertisement body remains an explicit import.

With phase 0xaa, counters over 60 reset to zero, log the heartbeat condition, write reply bytes 1–3 as 55/04/00, and set reply byte four to 60 only when the prior six-bit temperature exceeds the dock limit; otherwise it becomes four. Logging reloads that escaped reply byte at each live gate. Other counter values save reply voltage byte six only below 44; values at least 44 are replaced by the cached byte. Replies write exactly 23 bytes through the real SDK provider.

The field-control callback posts task flag `0x40`, cancels the existing battery-periodic callback with wildcard argument zero, then schedules that same battery callback at raw delay `0x2800`. It does not schedule itself. The stock literal at `0x32194` is `0x3d819`, verified by the captured callback identities. The parser separately schedules the field-control callback at `0x800`. Setter input truncates to one byte and getter zero-extends that byte. Public callback/policy APIs are void where results are discarded.
