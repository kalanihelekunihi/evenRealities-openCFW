# R1 GAP event policy and disconnect cleanup in C

`board/native_gap_events.c` implements the registered priority-three GAP observer at stock `0x52b9c`. It uses the existing peer-slot cache, connection fields, QWR contexts, advertising instance, control byte and factory-state owner. `runtime/native_ack_clear.c` implements stock `0x824a0` using the existing ACK registry and mutex. The sole new mutable owner is a byte at native `0x200064b0`, authenticated as zero in the stock cold RW image.

Connected events populate all seven bytes of slots 0–2 and assign the first free QWR context. The exact factory configuration value `0x5a` schedules the legacy timeout; a phone-present branch schedules the distinct adjacent legacy hook as its second callback. Their identities remain separate. The observer updates the latest handle and preserves returning error-handler behavior.

Disconnected events clear the first matching QWR handle and its peer slot, then handle glasses before phone. Glasses cleanup publishes its reason, cancels deferred target disconnect, clears the role handle, closes touch and resets two bytes in the existing factory state. Phone cleanup publishes its reason, clears control/role state, cancels its RX timeout and clears the actual ACK table. ACK cleanup logs occupied records, rereads the allocation after logging, frees it before clearing the occupied/callback/argument fields, preserves inactive records and returns the mutex-unlock status.

The advertising tail uses the typed S140 advertising-stop API, accepts status 0 or 8 and reports other errors. Restart mode 3 failures retain the earlier peripheral count for diagnostics and schedule the role callback at `0x66`. PHY requests route through the actual C PHY helper, using the event's captured settings for glasses and 1/1 otherwise. Completion and GATT timeout diagnostics retain stock routing and severity.

The controlled replay passes **1,696 stock/C comparisons**, including live backend mutations, all 32 ACK slots, QWR assignment failures, role precedence, advertising statuses, PHY events and logging branches. Connected-event population, actual peer lookup, disconnected-event clearing and actual peer lookup execute as a lifecycle. The actual C ACK, PHY, factory-reset, control-setter and pinned SDK QWR bodies execute together. All **1,910 native instruction bytes** in the observer, ACK-clear and factory-reset ranges are covered; all **18 compiled defect controls** are rejected. Callee-saved integer/FP registers, masks, SP, stack/table guards and public state/provider traces are checked. Source execution cannot enter stock executable addresses.

Backend logging, scheduler, connection-state results, status publication, touch service, advertising query/start, radio SVC results, mutex and heap service are modeled. The full higher connection consumer, physical radio, interrupt concurrency, final source layout and device boot are not established here. Private scratch-register restoration is outside the C contract. The stock adapter at `0x5e1dc` is simplified only for its observed disconnect domain through the existing status publisher.

The factory reset at `0x6a95c` cancels callbacks at `0x6a988` and `0x6a668`, then writes `0xff` to existing factory state offsets 3 and 4. Those two callbacks are explicit unresolved dependencies; no placeholder bodies were supplied. The broad GAP import closes, changing application imports from 71 to 72. Their implementation is the next analysis step.

The normal source build compiles **848 units**: 766 application and 82 bootloader. All **836 prior nongenerated objects** are unchanged. R1 manifest checking passes. Repository-wide checking retains the unrelated unlisted G2 `resident_rom_thumb_set.S` failure. No commit or device write was performed. Byte identity and a paid compiler are not requirements.
