# R1 autocorrelation C approximation corrections

REA analysis of stock wrapper `0x56d78` (66 bytes) and kernel `0x5c5f0` (1,326 bytes) establishes several corrections to the existing C approximation in `r1/src/vendor/gomore_primitives/gomore_primitives.c`. This work does not yet replace the native wrapper/kernel import in the classifier.

The kernel now uses strict positive tests for status gates and a strict peak threshold. Its second peak pass tests the sign of wrapped adjacent differences, rather than mathematical ordering of the original signed words. Variance scaling, negation and the strongest-minus-minimum difference also wrap explicitly. The direction-change share rejects ratios above the selected threshold, and the crowded-peak condition rejects a strongest value below 35% of the variance scale. Both conditions had been reversed in the approximation.

The ignored reproducible fixture is `build/goal-r1-gomore-autocorrelation-c/verify.py`. It executes the stock kernel and actual compiled C utility against 82 sample vectors, three floating-point environments and three initial second-status values: 738 pairs per compiler. Inputs include flat values, ramps, alternating extremes, square/sinusoidal waves across eight periods and three amplitudes, and deterministic full-range noise. Complete external memory agrees for all pairs. The strict GCC 9 probe also matches lower 28 FPSCR bits; its comparison flags differ in 36 cases. A Clang probe uses normal vendor compilation options with function/data sections added solely to isolate the utility for linking. Its complete external memory agrees, but floating-point status differences remain and are recorded in the receipt. It is not a proof of full FPSCR parity.

All three deliberately restored defects—an inclusive peak threshold, reversed weak-peak rejection, and reversed direction-change ratio—are rejected by native-versus-C memory comparison. The fixture checks return to the sentinel, SP and callee-preserved registers. It compares external memory and records FPSCR; it does not establish native raw R0/R1 return values, ordered writes, faults, arbitrary aliases, internal scratch addresses, device behavior or timing. The C checked utility and stock kernel have different return contracts. The fixture retains a stock memory-clear binding and therefore is not a source-only closure proof.

The normal R1 source build passes 718 units, with no failures or duplicate strong symbols and unchanged 178 application / 34 bootloader imports. Both source manifests pass. The composition receipt points to the fresh build. No instruction match, canonical source-plan change or hardware deployment is claimed. Further work must provide native-ABI wrapper/kernel C, resolve centered-ratio and direction-statistics boundary dependencies, and address floating-point status differences before claiming native-provider closure.

The roadmap now records the user's 2026-10-26 completion target: license-free C firmware, hardware support first, with byte identity and paid compilers removed as requirements. The locked stock image remains the behavioral reference.
