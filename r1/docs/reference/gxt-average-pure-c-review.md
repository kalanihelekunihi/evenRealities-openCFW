# GXT310 paired average with the ordinary C ABI

`runtime/native_temperature_average.c` no longer contains fixed-register declarations or empty inline assembly. It acquires the bus, enables the pair, waits 80 ticks, reads channels 0 and 2, disables the pair and releases the bus. Status returns do not skip cleanup. Addition wraps to 32 bits before signed division by two toward zero; multiplication by 100 wraps to the returned word. The caller receives the same C value without requiring a particular intermediate instruction or live R4/private frame layout.

REA's current analysis database does not expose `0x50e1c` as a function entry. A fresh REA raw-byte read captures the full 48-byte reference span; locked stock execution supplies the behavioral oracle. The new object passes 10,240 paired stock/C cases (20,480 executions) through the actual current C channel adapters. The probe rejects unintended stock instruction execution on the C route. Bus/mode/delay and final sensor conversion are modeled. Boundary and random full-word inputs, four provider statuses and two interrupt-mask states check independent signed/wrapping arithmetic, exact channel addresses, call order, settle delay, callee-saved registers, SP and masks. Four compiled defects are rejected: unsigned division, wrong second channel, wrong delay and missing bus release.

`build/sources-goal-r1-gxt-average-pure-c/report.json` compiles all 731 R1 units and composes both payloads without failures or duplicate strong symbols. Only the average object changes; all other 730 object hashes and export/import sets remain unchanged. Application imports remain 157 and bootloader imports 34. `make sources-check` passes.

The obsolete 48-byte exact selection was removed from the optional comparison source plan; no replacement selections were invented. Every other plan unit/region remains unchanged. The license-free hybrid comparison build succeeds in `build/hybrid-goal-r1-gxt-average-pure-c/`, retaining application SHA-256 `0e788d433ea50fd36edb8f21a9c18b6062211e4a36dbc5bd7695ea5827f3aa1a` with 4,311 source-built bytes, 641,849 pulled-through bytes and 248 resource bytes. It uses fallback for this average and does not integrate the new C average or prove source completeness. Source-built counts include assembly elsewhere; byte identity is optional reference evidence.

The frontier now marks this average and the earlier two RTC wrappers as having no current instruction identity or image integration proof, correcting their retired exact-selection metadata. The [earlier average review](gxt-average-c-review.md) retains historical instruction/frame evidence. [Machine-readable evidence](gxt-average-pure-c-review.json) records build hashes, raw REA bytes, tests, defects and plan audit. Probes live under ignored `build/goal-r1-gxt-average-pure-c/`.

Physical sensor/electrical behavior, timing, arbitrary faults/aliases/concurrency and a complete source firmware link remain unverified. The C-source migration is independent of the optional hybrid comparison's fallback coverage.
