# R1 touch worker and callback registration in C

`r1/src/application/runtime/native_touch_io_worker.c` implements worker `0x927c8`, callback registration `0x8e7b0`, and slider callback setter/trampoline `0x67460`/`0x93388`. It reuses the existing touch message queue, thread handle and ready-callback storage. The new watchdog and slider-callback words are zero in authenticated cold RW at `0x20006658` and `0x20007734`; final placement remains a linker gate.

The worker waits for startup group 9, creates a 50-by-44 queue, publishes it before checking allocation, registers callbacks, signals group 9, and registers the `touch` watchdog with timeout 10000. Each loop reloads the watchdog for arm, disarm and feed; it dispatches returned flags only when unsigned `flags - 1 < 0x7fffffff`. The existing C allocation-fault primitive handles a null queue, writing BASEPRI 64 before the deliberate zero store to `0xffffffff`.

Registration installs the existing ready IRQ callback, stores the slider state-machine address, then executes the existing power step. The slider setter rejects null without changing its word, or stores the full nonzero word and returns one. The ready callback and event-post wrapper execute as C in the test image. The slider state-machine address is stored only; its invocation ABI and behavior remain outside this change.

All 859 stock/C comparisons pass: 576 flag/watchdog/mask combinations covering every individual flag bit and validity boundaries, 256 seeded multi-wait cases, 21 registration/setter/IRQ and dispatcher-stop cases, and six allocation-fault cases. Checks cover publication order, callback identities, actual C ready setter and power step, actual IRQ event posting through the existing thread owner, live watchdog mutations, wait arguments, full flags, stack guards, preserved registers for returning adapters, and interrupt masks. Ten compiled defects are rejected before an unmodified-source rerun. REA byte receipts match the pinned artifact. A manual frontier entry records the independently decoded 116-byte worker instruction span, which lacked an earlier entry.

The normal build compiles 832 units (750 application, 82 bootloader), with no duplicate strong symbols. The touch-worker import closes and its dispatcher and slider state machine become explicit, raising application dependencies from 73 to 74. All 829 prior non-generated objects are unchanged; two generated bootloader objects differ. R1 source validation passes (832 units, 618 sources).

RTOS/sync/watchdog services and lower power operations are modeled. The touch dispatcher is modeled at its call boundary; these tests do not establish its suspend behavior or touch processing. Physical touch, timing, final application linking and boot remain unverified. Byte identity is not required under the current user instruction.
