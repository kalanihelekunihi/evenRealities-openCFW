# GPIO helper compiler-layout audit

The GPIO helper bodies behind the recently qualified table adapters remain
outside the byte-qualified plan. Fourteen production-source compiler variants
compiled successfully and selected no region. They vary size optimization,
literal-load preference, global inlining and restricted Thumb IT blocks while
leaving the pinned Nordic source unchanged. The official qualifier still
requires complete compile/link byte equality.

Global no-inlining adds calls and changes stack frames. A separate ignored
experiment applies no-inlining only to the SDK port decoder, leaving MMIO
operations inline. Its pin set/clear callers shrink to 22 bytes under the
smallest tested setting, compared with stock's 20-byte bodies; their frames
still differ. No production C source or manifest was changed to adopt that
experiment.

With restricted IT generation, that experiment's `nrf_gpio_pin_port_decode`
is 28 bytes and matches stock `0x79330` except at offset 23: source has `0xBF`,
stock has `0x00`. This lies in the two-byte alignment area after the normal
return instructions and before the literal. The instructions and literal
otherwise agree. That observation does not waive the full-byte requirement,
and no generated byte was patched.

All 33,816 normal-entry stock/source decoder comparisons pass over 4,227 pin
values, two aligned input words, Q-flag values and interrupt-mask states.
Checks compare R0-R12, flags, ordered literal/input-word accesses, updated pin
and guard bytes, exact executed-PC trace, SP/LR, interrupt masks and unchanged
stack. The alignment area is not executed in those runs. Alternate entry,
physical GPIO, complete faults and concurrency remain unverified.

The selective C file is an experiment, not a source-plan provider. The negative
matrix is limited to the tested Clang configurations; it does not prove that
all toolchains/configurations fail. Production firmware sources, manifest,
frontier, qualifier and canonical source plan retain their preceding hashes.
The previous full R1 composition remains 562 compiled units with no failures
or duplicate strong symbols and 210 application / 34 bootloader imports. No
G2 gate advanced. Exact compiler arguments, rejected qualification records,
source/header hashes and execution bindings are in the
[machine-readable audit](gpio-helper-compiler-review.json).
