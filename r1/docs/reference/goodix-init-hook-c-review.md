# Goodix initialization hook: watermark reset and entry ownership

The generated Goodix initialization hook now clears its two-byte FIFO watermark backup before querying reset recovery. Stock does this even when reset recovery suppresses algorithm reconfiguration. The pinned upstream default disables the optional ADT watermark policy, which previously omitted this clear and its state word. The local C header restores this specific stock behavior without enabling that broader policy.

REA and raw disassembly establish two separate entries: the 32-byte `gh3x2x_init_hook_func` at `0x6a500`, and the 38-byte `GH3X2X_AlgoCallConfigInit` at `0x29f58`. The earlier reference combined the hook and downstream functions into 110 bytes and assigned the algorithm routine to the hook address. The ownership CSV, frontier and driver mapping now distinguish them. The actual algorithm routine remains a missing dependency.

All 32 hook instruction bytes execute across 8,960 stock/C comparisons. Another 8,192 comparisons execute the actual reset-recovery getter. Checks cover every configuration-index byte, recovery edges, both interrupt masks, initial backup values, provider mutations, halfword width and clear-before-gate order. Configuration reads remain live after the gate, and provider mutations of the cleared backup survive. Five compiled defects and the previous normal-build hook are rejected.

The corrected normal serial build compiles 862 units with no duplicate strong symbols and unchanged imports (63 application, 22 bootloader). Its generated hook object equals the tested object. All 852 nongenerated objects remain identical. The sole manifest change replaces the upstream hook body with the local header; one canonical two-byte state definition is added. The source plan and cache layout are unchanged.

The direct fixture models reset recovery and algorithm configuration; integration executes the actual getter and models algorithm configuration. Saved integer/FP registers, SP, masks, FPSCR and guards are checked. Void return, caller scratch, private frame addresses and APSR are excluded. Native address placement is used only in probes. The algorithm memory provider and four-list configuration data still need recovery/binding. Physical sensor/watermark behavior, concurrency, final image layout, full application linking and boot remain unverified.

The final normal-build report is `build/sources-goal-r1-goodix-init-hook-c-body/report.json`. A superseded build was stopped after the probe caught a replacement matching the documentation signature; the final replacement matches the function body and passes the checks above.
