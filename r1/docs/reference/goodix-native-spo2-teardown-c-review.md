# Native SpO2 teardown and public shutdown adapters in C

The [machine-readable receipt](goodix-native-spo2-teardown-c-review.json) pins the new source, exact REA bytes, normal build, fixtures and results. `native_spo2_teardown.c` implements the complete native teardown graph under `0x6eb30`. `native_shutdown_adapters.c` adds the public HR and SpO2 deinit adapters. The implementation uses ordinary C, the existing C allocator and the canonical cell-release helper; no executable stock pointer or inline assembly is added.

The SpO2 parent accepts a null owner. Otherwise it reloads the canonical context owner before each nested operation and final free, clears that owner after free, and returns success. Its resource graph includes two unconditional buffer releases, an aggregate of sixteen session pointer cells and two descriptor pairs, an owned child, an optional context with a child at `+300`, a counted array, and a buffer with its own pointer cell. Three additional native cell-release entries share the existing canonical C provider. Future initialization must share the new four-byte owner at native address `0x20007ce4`.

The array destructor first checks descriptor `+1c`. Each loop check reads the live unsigned count and live array root, including the terminating check. It releases/clears `entry+14` at a 40-byte stride, then frees the current root. Aggregate, owned and buffer destructors also reload their roots after nested releases. These details preserve callback-visible state changes rather than treating all records as fixed snapshots.

Direct comparisons pass 816 parent field/count/gate cases, 2,040 helper cases, 520 live owner/root/count mutations and sixteen null-argument cases. Every nullable field is exercised individually and in masks. Count tests include growth, shrinkage and high unsigned values terminated by a callback count change. All 570 native teardown/shared-helper instruction bytes execute. Release callbacks record call-time state and clobber caller scratch registers; an independent normal-path oracle checks arguments and order.

The public status adapters ignore their frame and convert any full-word nonzero parent result to `-1`. Their separate fixture passes 4,160 comparisons, including values whose low byte is zero. Both native adapters execute all 36 instruction bytes. Parents are modeled for this status-range check.

Actual C heap integration passes 3,268 SpO2 comparisons through the native parent and public adapter, including both array-gate states, the null owner, roots before/after children and optional unrelated live allocations. Another 2,048 comparisons execute the public HR adapter with the actual C processing parent and every descendant across all 64 supported record type triples. Complete heap bytes, owner cells and write widths/order/values match. Source execution cannot enter stock code. Twenty-four compiled behavioral defects are rejected.

The null tests distinguish three supported null paths from thirteen initial unmapped reads. These are emulator access-shape observations, not claims of physical MCU faults. Saved integer/FP registers, SP, interrupt masks, FPSCR and caller guards are checked; caller scratch, APSR and private frames are excluded. Descriptor sizes and counts are bounded in the integration fixtures; concurrency and arbitrary corrupted descriptor behavior are not established.

The fresh serial R1 build compiles 874 units (792 application,82 bootloader), with no duplicate strong symbols and unchanged 62/22 imports. Both tested objects match the normal objects; all 862 prior nongenerated objects remain identical. Two existing generated objects differ with build directory paths. The manifest adds two units and the new canonical state is four bytes. Source plan and existing cache linker layout remain unchanged.

ADT/soft ADT shutdown, the top-level controller, native initialization/computation, physical sensors, final executable linking/startup and boot remain open. Typed fixture construction is not recovered algorithm initialization. Relocatable composition is not bootable firmware.
