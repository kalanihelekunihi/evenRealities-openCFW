# R1 touch-switch command entry in C

`runtime/native_touch_switch.c` now supplies the actual command-table symbol `r1_touch_switch_handler_plan_decode` for stock `0x84874`. The old `r1_native_touch_switch_handler` name is an alias at the same address. One ordinary C body replaces the assembly wrapper and separate kernel. A private initialized word supplies the acknowledgement byte; no saved-register frame is retained. The system table's declaration now matches its four-argument C callback type without changing that module object's bytes.

The handler uses the existing packed payload getter. A missing payload returns zero. Otherwise it sends the zero acknowledgement for command 7 before reading the live selector. Unknown selectors return their byte after acknowledgement. Phone selector 1 only reports the switch state. Glasses selector 2 reports the state, rereads it after diagnostics and opens or closes touch source 0. All existing touch client and thread owners are reused.

**6,378 stock/C comparisons pass**, covering every one of the **184 native instruction bytes**. The replay includes direct calls and the actual system module lookup, dispatcher and 20-command table. The packed payload getter, checked-send/header wrappers and touch services execute as real source bodies. Cases cover all 256 selector values, all 256 switch bytes, logging branches, handle/advertised-length guards, callback mutations and client ownership. All **11 compiled defects** are rejected.

The final protocol response backend, logging, RTOS flags and synthetic release are modeled. Other command handlers are unexecuted assertion stubs. The full ingress/BAE8 consumer, encoder/FIFO, IQS worker and physical touch hardware are outside this fixture. Callee-saved integer/FP registers, masks, SP, stack/input guards, scalar results, emitted response headers/data and public state/provider traces are checked. Source execution cannot enter stock code.

The caller audit confirms that the current system dispatcher tail-returns the scalar callback result, ingress restores its own frame before tail handoff, and receive validation returns a scalar result that the BAE8 consumer discards. Native private restored registers and acknowledgement addresses are outside the C contract; arbitrary external consumers of those registers are not covered. This is not a byte-identity or hybrid private-ABI claim.

The normal build compiles **849 units**, resolves the touch-switch import without new imports and leaves **69 application imports** plus 22 bootloader linker imports. All **838 other prior nongenerated objects** remain identical, including the module object after its declaration correction. No mutable state is added. Existing module/ingress/response assembly bridges remain unchanged. R1 manifest checking passes; repository-wide checking retains the unrelated unlisted G2 `resident_rom_thumb_set.S` issue. Final source layout, firmware linking, boot and physical hardware behavior remain unverified. No commit or device write was performed.
