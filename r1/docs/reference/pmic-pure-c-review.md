# PMIC charger decoding and byte commands use ordinary C

`native_pmic_charge_decode.c` no longer uses fixed-register declarations, empty assembly or stack-word helpers. Charger decoding uses four initialized local words; byte-write and single-wire adapters use an initialized local transfer word. The public C API returns status only. Private scratch bytes and incidental R2/R3 restores are retired.

The decoder still reads registers five, six and seven in that order, ignoring transport status. It requires register six's upper nibble to equal twelve, register five's upper three bits to equal five, and register seven's bit seven to be clear. It then reads register three. If bit six is clear, it writes that byte with bit six set. It returns one for the admitted condition even when the register-three read/write status indicates failure, matching stock.

The [receipt](pmic-pure-c-review.json) records 48,504 paired stock/C charger cases across 2,021 byte vectors. Cases cover every byte value in each field, randomized combinations, byte/full-word/no-write responses, bus status errors, incoming scratch seeds and live mutation of an earlier read byte. Results include 44,736 rejected and 3,768 admitted charger conditions. Another 288 paired cases cover the byte-write adapter, single-wire command and thunk, including full-width register/value/status inputs. Byte writes still request length one; the single-wire command still sends `0xf8` to register two. Four defective variants with wrong nibble, inhibit bit, enable bit or command byte are rejected.

REA raw-byte observations identify the stock decoder and adapter entries. Replay compares declared return status, transfer order, register addresses, byte lengths/data, balanced stack, callee-saved registers and interrupt masks. Transport callbacks are modeled. Private frame addresses, unused upper bytes and caller-clobbered scratch returns are excluded. Full-width writes in the decoder fixture remain within its four-byte local words; this is not arbitrary buffer-overwrite support. Physical PMIC, charger and bus operation remain unverified.

The normal report is `build/sources-goal-r1-pmic-pure-c/report.json`: 727 units compile without failures or duplicate strong symbols. Imports remain 178 application and 34 bootloader. Only the PMIC decoder object changed; 726 objects remain unchanged from the ship-mode checkpoint. Both manifests pass `make sources-check`. No byte identity or completed source-only firmware image is claimed.
