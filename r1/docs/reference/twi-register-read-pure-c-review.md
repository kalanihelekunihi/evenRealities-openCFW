# TWI register-read adapters use ordinary C

The primary and secondary register-read adapters in `native_hw_twi_register.c` no longer contain fixed-register variables, empty assembly or stack-word observations. They use a local register-command word and declared C arguments. Write-adapter code retains its separate frame implementation.

Both adapters transmit one register byte with no-stop enabled, wait, clear the busy byte, receive, and perform the final wait. Primary clears two control bytes initially, waits 500 first, and narrows receive length to a byte. Secondary clears only its busy byte initially, waits 100 first, and keeps full receive length. Both final waits use the original full-width length: 200 below fifty, otherwise 500. Each failure suppresses later stages before its status is narrowed to eight bits, including full-width failures whose low byte is zero.

The [receipt](twi-register-read-pure-c-review.json) records 7,560 direct stock/C cases with modeled legacy TX, another 7,560 executing the actual stock/C legacy TX wrappers, and 16,128 packet-chain cases through the existing C packet wrappers. Cases cover length boundaries, raw register/status values, every failure stage, ordinary/control-memory destinations, NULL output with no modeled write, transport mutation of the register word and control bytes, output bytes and unaligned packets. Return status, provider order/arguments, wait thresholds, control memory, final stack, preserved registers and masks agree. Four defects—wrong threshold, widened primary RX, uncleared primary control and untruncated status—are rejected.

REA raw-byte observations identify both stock entries. Scratch R2/R3 restores and private-frame aliases are retired for this C status API; active provider saved-register contents and private buffer addresses are excluded or normalized. SDK TX/RX and wait behavior remain modeled, even when the real legacy wrapper executes. Electrical operation, IRQ timing, arbitrary faults and concurrency remain unverified. No fully source-only bus image or byte identity is claimed.

The normal report is `build/sources-goal-r1-twi-register-read-pure-c/report.json`: all 727 units compile without failures or duplicate strong symbols. Imports remain 178 application and 34 bootloader. Only the register-adapter object changed; 726 objects remain unchanged. Both write-adapter instruction sections are byte unchanged. Both manifests pass `make sources-check`.
