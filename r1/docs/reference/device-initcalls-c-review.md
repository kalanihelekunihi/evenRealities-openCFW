# R1 device initialization dispatcher admitted to the normal source build

The existing `native_initcalls.c` now participates in relocatable composition and supplies `r1_boot_ctor_run` as an alias of its C boot dispatcher. This connects application startup to the thirteen existing ADC, internal-flash, hardware-TWI, named-GPIO, output-GPIO, RTC, software-I2C, charger-command and watchdog registration implementations. No duplicate dispatcher or provider bodies are added.

REA confirms the thirteen callback addresses and order in the locked artifact at `0xc4534..0xc4568`. The early and board ranges are zero/zero, and the post range is zero/zero. Their unresolved range symbols are removed in favor of the observed empty behavior. The device array remains thirteen symbolic C function references. The post helper at `0x5cb4c` is tested separately, but its 22 instruction bytes remain accounted within the existing boot inventory's 40-byte discontiguous body; no additional frontier row double-counts that tail.

The boot dispatcher disables interrupts, runs the device table, enables interrupts unconditionally and runs the empty post helper. Handwritten interrupt assembly is replaced by pinned CMSIS `__disable_irq` and `__enable_irq` intrinsics; the required machine interrupt operations still execute. Native behavior enables interrupts at exit rather than restoring the caller's incoming PRIMASK. Registration return statuses are discarded and do not stop the walk.

The dispatcher, device walker and empty post helper pass 174 stock/C comparisons. Cases cover incoming PRIMASK/BASEPRI values, callback return values, callback changes to interrupt masks and repeated module/boot/post sequences. Every callback's identity/order, observed interrupt masks and modeled side effects are compared, along with guarded memory, preserved registers, stack pointer and final masks. Reconstructed execution may not enter stock instruction addresses. Private scratch, caller-clobbered registers, APSR and void returns are excluded.

Eight compiled defects are rejected during execution: missing interrupt disable, missing enable, early enable, swapped ADC/internal-flash callbacks, swapped TWI callbacks, skipped watchdog registration, double registration and short-circuiting on callback status. The normal implementation was rerun afterward.

All 769 R1 units compile and both payloads compose without duplicate strong symbols. All 768 other object hashes are identical. The formerly excluded dispatcher now participates, and all thirteen referenced providers already participate with real C implementations. The `r1_boot_ctor_run` import closes with no new imports: 124 application and 34 bootloader dependencies remain. R1 source coverage passes. Global coverage retains the existing G2 `resident_rom_thumb_set.S` manifest omission.

See the [REA/table/range evidence](device-initcalls-c-rea.json) and [structured verification](device-initcalls-c-review.json). Registration callbacks are modeled in the dispatcher probe; this does not prove physical peripheral initialization or execute their provider bodies as one integration. Early/board/post extension tables, real IRQ concurrency, complete image linking and device operation remain unverified. Byte identity is not required for this build route.
