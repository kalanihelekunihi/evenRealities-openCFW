# Selector tail literal pool

0x468F04 through 0x468F24 is an aligned eight-word literal pool immediately after the selector function return at 0x468F02 and before the next PUSH at 0x468F24. Preserve all 32 bytes as data. Values are raw little-endian words; pointed-to object contracts remain unresolved. This record does not establish whole-corpus coverage or authorize C implementation.
