# Length-guarded helper and global-record validation/reset

Partial/unaccepted;124 instruction bytes, three entries 47D9FC,47DA16,47DA58.
D9FC: PUSH R7,LR eight bytes. Read unsigned word [entryR0+12] once. If >=4501, R0=0; otherwise call 4D34C4(entryR0,20,0,liveR3) and retain full result. POP R1,PC sets R1=saved entry R7. Zero length is allowed by this routine.
DA16: PUSH R4,LR eight bytes; R4=word literal47DC30 (record pointer). Fresh word0 must equal literal47DC34; fresh word4 must equal1; first fresh word12 must be nonzero; a second independent word12 must be unsigned <4501. Each failed guard returns0. Successful guards call D9FC(record,liveargs), which reads word12 a THIRD time and can return0 if that fresh value is >=4501. Afterwards fresh word20 is compared with full returned R0: equality returns1, inequality0. Thus zero helper return can still produce1 when fresh word20 is zero. POP R4,PC restores entryR4; no snapshot/atomicity assumption.
DA58: PUSH R3,R4,R5,LR16 bytes. R4=literal47DC30 pointer; fresh word0 compared with literal47DC34. Equality skips all writes/helper calls. Inequality sets R1=4524,R2=0,R5=R4,R0=R5 then calls43C0E4(record,4524,0,liveR3); after normally returning helper, writes word8=0. POP R0,R4,R5,PC restores R0 from saved entryR3, so no boolean/helper-result return. External helpers remain opaque dependencies. No C/freeze/whole coverage claim.
