## 4. G2 RF data (2BFKR-G2)

EUT description (report §4): operating frequency 2402–2480 MHz; GFSK;
40 channels, fc = 2402 + 2k MHz (k = 0…39); LDS antenna; gain L −1.81 dBi,
R −2.06 dBi; engineering test firmware in continuous-TX mode; only 1 Mbps
reported ("worst mode … highest RF output power at preliminary tests");
temporary antenna connector soldered on the PCB for conducted tests.
