## Magnetometer behind the IMU

Aux I2C address 0x1E; chip-ID register 0x01 reads 0x45. The vendored TDK
driver defines `ICT1531X_WHOAMI 0x45`
(`g2/third_party/invensense-icm45608/src/Ict1531x/Ict1531x.h:33`), so the
magnetometer is likely a TDK ICT1531x [INF Medium].

## Register map / SVD

Register definitions are in the TDK driver headers under `src/imu/`.

## Relevance to decompilation

The stock EDMP RAM images (`edmp_ram_*_image.h`) in the TDK driver are byte
arrays that should match blobs in the Apollo image; use them to label data.
