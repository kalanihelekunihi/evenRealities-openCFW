# JBD (Jade Bird Display) JBD4010 microLED panel

**Used in:** G2 glasses, per temple, as display panel variant 0 (the other
variant is the [Hongshi A6N-G](hongshi-a6n-g.md)). Tags:
[vocabulary](../README.md#confidence-vocabulary).

## G2 use (FW)

MSPI0, serial for commands and reads, quad for pixel writes, 640×480 at
4 bpp (320 B/line). Commands 0x66, 0x99, 0x06, 0x01, 0xC0, 0x97 (latch),
0x73, 0x36, 0x46, 0x31, 0xA3, 0xA9; status 0x05/0x35; modes 0x71–0x74;
offsets X 2..22 / Y 2..18. Recovery by status check → power cycle →
reconfigure → redraw.

## Register map / SVD

None public. The recovered command list above is the only register-level
information.

## Relevance to decompilation

Label the ULED ops table (64 B) and the MSPI0 transfer helpers; the panel
selection byte (`0x06` ⇒ A6N-G) decides which table is used.
