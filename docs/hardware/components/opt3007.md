# Texas Instruments OPT3007 (ambient light sensor)

**Used in:** G2 glasses, master (right) temple only, for auto brightness.
Tags: [vocabulary](../README.md#confidence-vocabulary).

## Identification

| Evidence | Tag |
|---|---|
| Driver path `driver\sensor\als\opt3007\opt3007_registers.c`, function `ti_opt3007_assignRegistermap` (19 register triples, mfr ID reg 0x7E, device ID reg 0x7F) | FW High (`g2/docs/research/g2-opt3007-registers-recovery.md:1-14`) |
| Community reads manufacturer ID 0x5449 and device ID 0x3001 at address 0x45 and names the part OPT3001; opened only on the master lens | COM (https://github.com/jimrandomh/g2flash `patches/als_sensor.c:9-11`) |

The OPT3007 datasheet gives manufacturer ID `5449h`, device ID `3001h` and
fixed address `1000101b` (0x45), the same values as the OPT3001, so the
IDs do not separate the parts. The firmware path names OPT3007 [INF].

## Key specifications (DS)

| Item | Value |
|---|---|
| Range | 0.01 lux to 83k lux, 23-bit effective dynamic range, automatic full-scale |
| Supply / current | 1.6–3.6 V; 1.8 µA typical |
| I2C | Fixed 7-bit address 0x45; standard, fast (400 kHz) and high-speed (2.6 MHz) modes; 5.5 V tolerant I/O |
| Package | Ultra-thin PicoStar (YMF), 6 pins, ≈0.856 mm class |
| Registers | Result 0x00, Configuration 0x01, Low limit 0x02, High limit 0x03, Manufacturer ID 0x7E (0x5449), Device ID 0x7F (0x3001) |

## Relevance to decompilation

Bus number on the Apollo side is not yet recovered; the 0x45 address and
0x7E/0x7F reads locate the driver's I2C calls.
