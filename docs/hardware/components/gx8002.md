## Key specifications (DS / vendor pages)

| Item | Value |
|---|---|
| Architecture | MCU + NPU: C-SKY (T-Head) CK804 32-bit with DSP and FPU; gxNPU V200 (DNN/CNN/DS-CNN/LSTM/GRU, 8-bit) |
| Memory | 208 KB SRAM; 256 KB or 512 KB SPI NOR in-package (SiP) |

## G2 use (FW)

| Item | Value |
|---|---|
| Control | Apollo UART3, 115,200 baud, `BUXX` framed commands (see [g2-glasses.md](../g2-glasses.md#4-inter-processor-links)) |
| Audio | I2S out, 2 ch, 16 kHz, 16-bit (GX pins 7–10 mux mode 3); GPIO2 notification line |
| Power | Apollo logical GPIO 6/7/8 sequencing (5 ms / 20 ms) |
| Boot / DFU | UART at 230,400 → 1,000,000 → 1,500,000 baud; stage 1 (10,240 B) → IRAM `0x10000000`, entry `0x10000100`; stage 2 (27,964 B) → `0x10002800`, entry `0x10002900` |
| NOR layout | Image A `[0,0x2F3B0)`, backup image B `[0x2F3B0,0x46440)`; XIP base `0x10200000` (public default) |
| Runtime memory | NPU owns IRAM `0x10000000..0x10023400`; SRAM text/data at `0x10023400..0x10026D7C`; SP `0x2002F7FC`; KWS model `[0xF804,0x2F3B0)` of image A |
| Firmware version | 0.0.2.3; LVP bare-metal event loop, watchdog 3000 ms |

## Relevance to decompilation

Disassemble as C-SKY ABIv2 (CK804EF). Load stage 1/2 at the IRAM addresses
above and image A as XIP at `0x10200000` (INF: public default).
