## G2 use (FW)

MSPI1 CE0, SPI mode 0, 96 MHz, READ `03h`, quad-output read 4-byte `6Ch`
(8 dummy), PP `02h`, SE `20h` (4 KiB), EN4B `B7h`. Pads GPIO49 (CS), 95–98
(D0–D3), 103 (SCK). XIP at `0x80000000`. littlefs v2.10.1 at device offset
`0x01400000..0x01FC0000` (`g2/docs/research/littlefs-g2-mspi-transport-audit.md:7,68-81,120-176,260-285`).

Not applicable (command-set device). The datasheet command table is the

## Relevance to decompilation

Label the XIP window and the littlefs block device callbacks; the NOR
contents are not part of EVENOTA except files written at runtime.
