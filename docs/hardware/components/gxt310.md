## Key specifications (DS)

Factory-calibrated 16-bit I2C/SMBus sensor optimised for body temperature;
±0.1 °C; −40 to +125 °C; 1.6–5.5 V; 3 µA standby; WLCSP-4 0.7 × 0.7 mm
(GXT310W0).

## R1 use (FW)

Software TWI `i2c_2` (SCL P1.13, SDA P0.28); temperature register 0x00,
signed big-endian, 0.0078125 °C/LSB.
