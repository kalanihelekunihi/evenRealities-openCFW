## Protocol (FW)

See [r1-ring.md §5](../r1-ring.md#5-pmic-yhmicros-yhm2710-single-wire-protocol):
7-bit header with bit 6 set, R/W selector pulse, 8 data bits MSB first with
XOR parity, 52/13-count pulse encoding; registers 1, 2, 3, 6, 9 used.
