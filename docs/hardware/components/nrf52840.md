the G2 does not use Nordic MCUs.) Tags: [vocabulary](../README.md#confidence-vocabulary).

## Key specifications (DS)

| Item | Value |
|---|---|
| Core | Arm Cortex-M4F, 64 MHz |
| Memory | 1 MB flash, 256 KB RAM |
| Radio | BLE 5, IEEE 802.15.4, NFC-A tag |
| Peripherals | 2× TWIM (shared with SPIM), SAADC 12-bit 8 ch, GPIOTE, RTC0–2, WDT, USB FS |

## R1 use (FW)

TWIM0 (touch), TWIM1 (motion), four GPIO-driven software TWI buses, SAADC
AIN2/3/5, RTC2 at 8 Hz, WDT; see [r1-ring.md](../r1-ring.md).

## Relevance to decompilation

Use the nrfx SVD for peripheral labels; SoftDevice S140 7.2.0 occupies
`0x00000–0x26FFF` and the application starts at `0x27000`.
