# Tool and SDK availability survey (as of 2026-09-29)

Scope: availability, access requirements, licensing and exact-version obtainability of the
compilers, SDKs and analysis tools relevant to the G2 (Apollo510 / EM9305 / GX8002 / PSoC 4 /
STM32G0) and R1 (nRF52840) firmware work.

Method: official vendor pages, vendor GitHub/GitLab repositories, package indexes (PyPI), and
direct unauthenticated HTTP range requests / `git ls-remote` against official download URLs
performed on 2026-09-29. "Verified" means an anonymous request to the official URL succeeded on
that date. "Unconfirmed" means the claim comes from a secondary source or could not be checked
without an account.

Key for "Account/registration": **None** = anonymous download verified; **Login** = vendor
account required; **Customer/NDA** = only via sales, subscription, or customer relationship.

Reminder for byte-identical rebuilds: only the *exact* compiler build (and its bundled runtime
libraries) used for the official artifact can satisfy the target. Free alternatives listed below
are useful for analysis, experiments and equivalence testing, not for byte identity.

## Summary of access constraints

**Login / registration required**
- IAR trial (register.iar.com) and IAR MyPages (subscribers only).
- Arm Compiler 5 (Arm account on support.arm.com PDH).
