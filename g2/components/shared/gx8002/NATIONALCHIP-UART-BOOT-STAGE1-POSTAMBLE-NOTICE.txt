NationalChip UART boot stage-1 rail postamble leaf notice (openCFW)

The reviewed source in
components/shared/gx8002/runtime_gx8002_uart_stage1_postamble.S is
clean-room assembly written from decoded stock control flow. No
NationalChip SDK source text is reproduced and no SDK register map is
used: the only absolute address in the body is the numeric pointer-cell
constant 0x20002274 observed in the decoded stock flow, loaded through
the assembler's own end-of-section literal pool (the numeric-lrw
precedent of the reviewed stage-1 reset entry). All other behavior is
register traffic, numeric immediates, and the noreturn call into the
reviewed first PMU dispatcher leaf. The pinned upstream SDK checkout
is not a build input to this leaf.
