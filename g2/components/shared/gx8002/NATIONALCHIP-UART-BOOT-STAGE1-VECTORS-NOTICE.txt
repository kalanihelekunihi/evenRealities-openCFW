GX8002 UART boot stage-1 vector table and trap entries
Local source: runtime_gx8002_uart_stage1_vectors.S (clean-room, MIT)
No upstream file is adapted or reproduced here. The table layout (reset
word followed by 31 exception words and 32 IRQ words) follows the CK804
64-entry vector-table convention already documented for the image-A/B
stage-two bodies in g2/tools/manifests/g2-codec-stage2-section-map.tsv;
the three addresses (reset 0x10000100, exception trap 0x10000130, IRQ
trap 0x10000134) and the branch-to-self trap shape were recovered from
the decoded stock stage-1 bytes (see
docs/research/gx8002-uart-boot-stage1-cd001-analysis.md and
docs/research/gx8002-uart-stage1-vectors-source.md). The reset-entry
address matches the reset prologue reconstructed in
runtime_gx8002_uart_boot_stage1_reset.S, which is derived from
NationalChip/lvp_kws arch/cpu/csky/ck804/spl_start.S at commit
8bf9ee5cb6eeb226011e61c15fa4981b83b93bd5 (see
NATIONALCHIP-UART-BOOT-STAGE1-RESET-NOTICE.txt); no text from that file
appears here.
