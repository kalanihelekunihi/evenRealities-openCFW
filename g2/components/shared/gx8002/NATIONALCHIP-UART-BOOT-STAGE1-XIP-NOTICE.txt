NationalChip UART boot stage-1 XIP transfer adaptation
Upstream: NationalChip/lvp_kws arch/soc/grus/include/base_addr.h
(GX_REG_BASE_XIP = 0xA2000000, the XIP flash controller base)
Commit: 8bf9ee5cb6eeb226011e61c15fa4981b83b93bd5
Local source: runtime_gx8002_uart_stage1_xip.c
Recovered XIP-controller behavior: both leaves wait for idle (status bit 0
at offset 0x28), snapshot the status word into the configuration registers
at 0x08 and 0x4c, then issue a command word through the data register at
0x60. The read leaf programs control 0xC07 with count = len - 1, polls
data-ready bit 3, and stores each received word narrowed to a byte; the
write leaf programs control 0x407 with count = len (shadowed shifted by 16
into the mode register at 0x18), polls transmit-ready bit 1, and writes
each source byte widened to a word. Both finish by waiting for a zero
residual count at 0x24 and idle status. All register offsets, control
words, and poll bits were recovered from the decoded stock control flow.
Only the numeric controller base is taken from the upstream header (used
under the SDK repo-level MIT LICENSE below); all bodies are clean-room
implementations of the decoded stock behavior. No other SDK header or
source (in particular the proprietary spl_spinor.c/spl_spi.c drivers and
the GPL-licensed common.h/spl.h) was used.
