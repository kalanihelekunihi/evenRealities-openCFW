NationalChip UART boot stage-1 PMU dispatch leaf notice (openCFW)

The reviewed source in
components/shared/gx8002/runtime_gx8002_uart_stage1_pmudispatch.S is
clean-room assembly written from decoded stock control flow. No
NationalChip SDK source text is reproduced and no SDK register map is
used: every address the leaf touches arrives through the descriptor
filled by the reviewed `pmu_fill_desc` leaf or through the two
retained jump-table base addresses named in the file, and every other
constant in the body is a numeric immediate observed in the decoded
stock flow. The pinned upstream SDK checkout is not a build input to
this leaf. A clean-room C draft of the same leaf was attempted first
and abandoned: every probed toolchain shape compiles to at least 298
bytes against the 264-byte stock envelope (see
docs/research/gx8002-uart-stage1-pmudisp-source.md), so the reviewed
assembly is the admitted form.
