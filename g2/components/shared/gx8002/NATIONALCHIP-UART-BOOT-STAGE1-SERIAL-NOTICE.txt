NationalChip UART boot stage-1 polled-UART adaptation
Upstream: NationalChip/lvp_kws arch/soc/grus/spl/spl_uart.c
(serial_put, serial_put_sync, serial_try_get, serial_get_char) and
arch/soc/grus/include/base_addr.h (GX_REG_BASE_UART0/UART1)
Commit: 8bf9ee5cb6eeb226011e61c15fa4981b83b93bd5
Local sources: runtime_gx8002_uart_stage1_serial.c,
runtime_gx8002_uart_stage1_putsync.S
Recovered UART-boot configuration: the UART block base is held in the
stage-1 data word at 0x20002014; line-status at block offset 0x14
(bit 6 transmitter-empty, bit 0 data-ready); data at block offset 0x0
(word write for transmit, word read narrowed to a byte for receive).
Only numeric register offsets, bit positions, and call/return conventions
are taken from the upstream file (which carries no per-file license header
and is used under the SDK repo-level MIT LICENSE below); all bodies are
clean-room implementations of the decoded stock behavior. The GPL-licensed
SDK headers (common.h, spl/spl.h) were deliberately not used.
