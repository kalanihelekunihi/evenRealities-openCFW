GX8002 UART boot stage-1 baud-beacon/bring-up leaves (CD-001): clean-room statement
================================================================================

Files: components/shared/gx8002/runtime_gx8002_uart_stage1_beacon.S
Symbols: open_cfw_gx8002_uart_stage1_beacon, open_cfw_gx8002_uart_stage1_bringup
Ranges: runtime 0x100004D0, package 0x520, 180 bytes; runtime 0x100005C4, package 0x614, 92 bytes.

The assembly in this file was written from the decoded control flow of
the stock GX8002 UART boot stage-1 image (used only as an analysis and
differential-test oracle). No vendor source was consulted and no vendor
object or SDK text is reproduced: the 0x20002008/0x20002014 cells, the
0xA0100000/0xA0200000 bases, every register offset, dispatcher id, and
constant is a numeric immediate observed in the decoded stock flow. An
abandoned draft is not applicable: the first reviewed form assembled
byte-identical to both stock envelopes (180/92 bytes, exact fill, no
relocations) once internal branches used symbolic labels (the C-SKY
assembler silently drops branches written with absolute address
operands; see the audit doc).
