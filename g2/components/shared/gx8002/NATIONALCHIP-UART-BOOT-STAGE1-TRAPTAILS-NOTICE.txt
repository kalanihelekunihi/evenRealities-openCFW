GX8002 UART boot stage-1 rail-configure/block-clear trap tails (CD-001): clean-room statement
============================================================================================

Files: components/shared/gx8002/runtime_gx8002_uart_stage1_traptails.S
Symbols: open_cfw_gx8002_uart_stage1_railcfg, open_cfw_gx8002_uart_stage1_blkclr
Ranges: runtime 0x1000046C, package 0x4BC, 56 bytes; runtime 0x100004A4, package 0x4F4, 44 bytes.

The assembly in this file was written from the decoded control flow of
the stock GX8002 UART boot stage-1 image (used only as an analysis and
differential-test oracle). No vendor source was consulted and no vendor
object or SDK text is reproduced: the 0xA0400000/0xA0500000/0xA0600000
bases, every register offset, dispatcher id, and constant is a numeric
immediate observed in the decoded stock flow. An abandoned draft is not
applicable: the first reviewed form assembled byte-identical to both
stock envelopes (56/44 bytes, exact fill, no relocations).
