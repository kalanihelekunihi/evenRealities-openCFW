# Apollo-main FreeType CFF scatter provider

This directory contains the target-specific post-link stage for the admitted
FreeType 2.9.1 CFF engine.  It replays the checked dual-profile scatter link,
guards the complete stock CFF interval and stock module-class pointer, writes
the four finalized sections, and only then replaces the class pointer.  The
result is one Apollo-main payload ending below the update flag, with its nested
size and CRC-32 renewed.

The apparent scatter is still one atomic EVENOTA component: bytes between the
current profile-specific application end and the fixed tail section are emitted
as `0xFF` generated erased padding.  No byte from the separately catalogued
360-byte old table/callback pool is used.

`build_component.py` emits a component and a fail-closed receipt.  The
canonical Apollo core builder invokes it after the liblc3 and product-test
post-link providers and publishes the resulting component through its existing
rollback-capable atomic generation.  Package TOC length/CRC, full package pins,
and flash-plan ownership are regenerated by the package integration verifier;
this stage never flashes hardware.  Physical G2
execution, font payload qualification, stack/WCET qualification, and rollback
behavior remain outside this software-only closure.
