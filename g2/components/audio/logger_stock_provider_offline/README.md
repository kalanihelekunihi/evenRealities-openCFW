# Offline stock logger providers

Ten selected function bodies retain unchanged pinned Apollo510 SDK text and BSD3 notices. Fixed-address/status/bitfield definitions in compat.h recover the tested main-image ABI. These are offline knowledge/source artifacts, not production firmware modules or a source-complete driver.

Build and validation live in [analysis](../../../analysis/audio-logger-stock-provider-closure-2026-10-09/REPORT.md). Existing GPIO configuration and interrupt-mask source are reused unchanged. Delay and peripheral power are four explicit original-address aliases; tests substitute synthetic external return/query behavior. Never describe this ELF as a closed whole-source firmware build or proof of hardware completion.
