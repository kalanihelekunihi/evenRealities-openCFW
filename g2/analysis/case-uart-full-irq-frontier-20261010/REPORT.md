# CASE full UART IRQ source frontier

The fixed CASE image is `g2-2.2.6.10/firmware_box.bin`, SHA-256 `36ca0c13558f252af286ae2b36b5e576d087d21d37b15d778e7da9f502a70374`. Its single `HAL_UART_IRQHandler` is `0x08005f50..0x08006230`; the exact decoded slice is retained in `case-remaining-direct-frontier-20261010/irq-original-disassembly.txt`. The archive imports `case_uart_other_irq` and `case_uart_dma_boundary` are candidate split points inside that one entry, not stock callable functions. The existing `uart_error_atomic_offline/uart.c` source and corrected 6,768-case comparator cover the RX/error prefix and `UART_EndRxTransfer`; they stop at `0x08006086`, exclude DMAR, and verify PRIMASK at prefix MMIO writes. They do not prove either split import.

The pinned STM32G0 `stm32g0xx_hal_uart.c` retained in `case-uart-error-atomic-closure-2026-10-08` contains a full `HAL_UART_IRQHandler` starting at source line 2300. Its control structure explains the stock branch order and is a strong source provenance lead, but the retained prefix comparator compiled an independent selected scaffold. The full vendor body has not been compiled and compared under the product's headers/configuration and callback bindings.

This branch inventory uses stock instructions plus the pinned HAL source to name paths; it does not infer physical UART/DMA behavior from RAM fixtures. A complete source-defined archive provider should replace the two split imports with one public-entry handler or a rigorously proven continuation ABI. Its comparator must start both original and source at the public handler, cover each row with coherent UART/DMA structures and callback writes, assert the full handle/peripheral/DMA RAM windows and PRIMASK at every atomic MMIO write, and stop explicitly at lower callbacks whose bodies are not source-owned. The existing TOIDLE no-op callback and RX completion parser do not cover DMA abort or TX completion.

No full-body C was integrated because the required DMA/callback and TOIDLE/TX original/source matrix does not exist. The archive remains 37 objects, 61 provided symbols, five unresolved imports (four direct names, one lower formatter), direct CASE count **8/12**. The two synthetic IRQ names represent **one stock handler body** and at least seven branch families above; the remaining effort is a full-handler source build and branch matrix plus lower callback contracts, not two independent small stubs. Startup/link, actual DMA/peripheral state, output delivery and hardware validation are separate boundaries. No duration estimate is supported by the present fixtures.

The subsequent isolated `case-uart-toidle-branch-20261010` comparison now closes the **non-DMA TOIDLE selected branch** with 256 public-entry original/source fixtures, including partial and no-partial counts, full handle/MMIO state, event callback arguments and PRIMASK at atomic writes. The full-handler and DMA/TX frontier above remains; this branch source is deliberately outside the archive.

The same isolated analysis now also closes the **TOIDLE DMA selected branch** with 1,280 public-entry original/source fixtures and a common compiled `HAL_DMA_Abort` fixture provider. It checks DMA channel/handle state, abort call and event arguments, handle/MMIO windows and PRIMASK. This revealed a concrete divergence from the retained HAL source: the stock body returns on circular full-count rather than emitting an event. That branch does not cover error-triggered DMA abort, wakeup or TX/FIFO paths; the full handler and archive imports are still open.
