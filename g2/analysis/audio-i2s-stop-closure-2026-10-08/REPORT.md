# I2S stop software ordering and clock-client release

**1,296 PASS comparisons**: 1,280 selected stop cases and 16 independent matching-source register-configuration cases. [Independent C](../../components/audio/i2s_stop_offline/stop.c), [results](results.json), [disassembly](original-disassembly.txt), [provenance](provenance.json). This closes selected software below the earlier DMA-stop entry boundary; it does not establish physical stop.

Original `0x590C62` first reads handle+4 before its NULL check, so a mapped non-NULL handle is required. Low25 handle bits must equal `0x01125125`; invalid marker returns 2. Enabled bit25 clear returns 0 without changing registers. Module0 uses software peripheral index29; module1 uses30. An enabled handle first calls `0x4C4530(4,index)` to release clock-group4 membership. If handle+0x60 is nonzero, it clears bits0 and12 of control register `0x40208100 + module*0x1000`, invokes `0x58FDBC(module,0x217)`, maps handle+0x5C through `0x58FD1C`, and releases the mapped clock group. It then clears handle bit25 and returns0. Status from the clock-release dispatcher is ignored here.

Software clock-client table is `0x20073324`, seven groups of two words. Real `0x4C4016` removes group4 client membership under saved PRIMASK. If another group4 client remains, it restores PRIMASK and returns. If this was the last client, it enters **`0x4D391E(0)` before the DMA register writes or handle marker clear**. Tests stop before that provider's first instruction; its return and power effects are not fabricated. This is an available further provider, not a global exhaustion boundary.

## Register configuration scope

Request0x217 is decoded as enable-byte0, source-byte2, divider23. Under matching current source2 (synthetic clock-selector register `0x400204E8`, module0 bits5..6/module1 bits7..8), actual `0x58FDBC` clears bit0 of auxiliary register `0x40208054 + module*0x1000`, clears control bit12, sets control bits16..18 to4, restores bit12, and changes divider bits4..8 to23 when different, preserving the original control bit0 during that divider update. The independent helper reconstructs this exact selected branch and ordered writes. In the stop caller, bits0/12 were already cleared. Source-changing branches elsewhere in `0x58FDBC` are disassembled, but not reconstructed or tested by this helper.

Stop fixtures vary module0/1, valid marker, enabled flag, active byte, divider7/23, control bit12, software client membership, another group4 client, and five source-config values0/0x200/0x208/0x20F/0x217. Other clock-client groups are initially empty; `0x40004048` is synthetic zero for the clock-source2 selection of config0x20F. Separate direct reconfigure cases vary divider0/7/23/31 and bit12. Stop C shares actual clock-release/source/reconfigure peers; separate reconfigure C uses its own register stores. Returns, handle/client-table state, PRIMASK, call arguments and ordered register writes match, with independent no-write/marker expectations.

These are **passive MMIO fixtures**. No DMA engine, in-flight completion, interrupt delivery, clock stability, physical I2S/PDM behavior or hardware handshake is simulated. A returned0 is the stock software return in this fixture, not a claim of completed hardware quiescence. Live reentry and producer coordination remain separate prerequisites.
