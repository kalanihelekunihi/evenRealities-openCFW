# Bounded kernel tick candidate, 2026-10-10

**Status: complete for five assigned function semantics.** Canonical workflow remains `P2_EXECUTING`; this isolated C candidate does not alter G2-G6 gates or establish source completeness or byte equality.

The official `ota_s200_firmware_ota.bin` stripped of its 32-byte OTA header has SHA-256 `19044a72bdfeb04c6b1b104d87da7b98e13cc18928528d84d999b6bcc0ba9701`, length 3,523,364 and base 0x438000. The literal at 0x4557ac identifies the tick cell 0x20074a34. Literals 0x456064/68 identify scheduler state words 0x20074a3c/0x20074a58. Original disassembly in `g2/analysis/coverage-audit-parallel-2026-10-09/TDK-TRANSPORT-MAIN-DISASSEMBLY.txt` shows `IS_IRQ` at 0x44900e..0x44903c, CMSIS wrapper at 0x4490cc..0x4490e2, task getter 0x454efe..0x454f06, ISR getter 0x454f06..0x454f10, and state provider 0x4558a4..0x4558c4.

`tick.c` reconstructs all five. The distinction between task and ISR getters is a stock call-path distinction; both return the same tick word. `IS_IRQ` returns true when IPSR is nonzero, or when scheduler state is not 1 and either PRIMASK or BASEPRI is nonzero. Scheduler state is 1 when active word is zero, 2 when active is nonzero and suspended is zero, otherwise 0. The explicit `mrs` instructions are disclosed source-level architecture dependence.

`verify.py` rechecks image SHA and literals, compiles the source for Cortex-M55, and executes both original functions and the Cortex-M4 build in Unicorn. Across 648 fixture combinations of active/suspended state, IPSR, PRIMASK, BASEPRI and four tick values, the five functions plus the flash database adapter passed 3,888 equal-return comparisons, with untouched observed RAM, restored SP and proper return. Both wrapper branches were reached in original bytes. The M4 emulator build is used because an M55-only `cset` instruction is not supported by Unicorn's M4 CPU model. Results and commands are in `results.json`.
