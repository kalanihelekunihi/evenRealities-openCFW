# Static discriminators and locked target candidates

## Result and corrected acquisition assessment

Of the 68 byte-different NationalChip source/header files, 25 are comment/whitespace-only under a simple lexical heuristic, and 43 retain other differences. This heuristic is not a C parser; explicit inspected diffs establish the UART-message and boot-board changes are copyright-only. UART framing is therefore a shared-family comparator, not a discriminator between these pins. `static-diffs/` retains inspected file comparisons. `nationalchip-comparison.json` carries the heuristic flags.

The locked codec has active VAD format-string evidence favoring the existing KWS source branch over unmodified AIoT: raw strings `[LVP_AUD]vad param {1,2,3} [%d]\n` occur in two embedded images, while AIoT comments out their calls. This is a branch discriminator, not exact producing-source attribution; private patches, another revision or unused retained data can also explain strings.

## Bound identities and target verification

Locked codec: `g2/blobs/official/g2-2.2.6.10/firmware_codec.bin`, 326092 bytes, SHA-256 `b06dfef7faa2f1e52d2aacd07958d4b96ffc36dca5077ac9149e48f19fc9c4d0`.
Locked BLE: `g2/blobs/official/g2-2.2.6.10/firmware_ble_em9305.bin`, 211948 bytes, SHA-256 `91a38f7fc05555f86181ecb22b363e3239bfcaaa2ff6171e98524ae64821eca9`.

Both hashes were recomputed and agree with workflow target identities. `locked-target-candidates.json` copies 13 selected codec symbol rows and independently recomputes each stock slice hash using its recorded package offset; all 13 match. This verifies target identity only. Source-vs-target opcode or relocation-normalized attribution was not performed. `locked-string-evidence.json` records all raw payload-offset occurrences; offsets are not virtual addresses.

## Provenance and owner integration proposal

Current public URLs were verified by successful anonymous git ls-remote and clone. Acquisitions are detached at the exact verified HEADs, and per-file SHA-256 is in `provenance.json`. No downloaded script/build/test was run. Root licenses do not supersede bundled file terms: NationalChip vectors.S explicitly Apache-2.0; other bundled components retain their own notices.

Proposed .gitmodules text is in `PROPOSED-GITMODULES.txt`. These are comparison-only proposals, not modifications to root .gitmodules or index. Exact gitlink commits must be reviewed and set by owner. Prefer existing registered lvp_kws for all identical/common code; AIoT is useful only for differential lineage and its new paths. Neither proposal proves source completeness or byte identity.

See FINAL-CONSTRAINTS.md and vad-callsite-byte-checks.json for six byte-validated string-load/call instructions. They establish local executable references, not reachable calls.
