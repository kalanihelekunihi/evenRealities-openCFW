These nine new source units are selected in the separate 242-unit image-B target build, `build-stage2-entry-round/receipt.json` (linked object SHA-256 `fd98debc05bba630e52726cbe09caf43f64433bec2ab5f8a8ed16c65f7e27cde`). Thirteen genuine code/data imports remain. No stock executable byte array or fake hardware result is used. The generic IRQ at `0x10004880` retains a compact-ISA assembler/toolchain gate; a vector relocation alone does not implement it. The physical IRAM/DRAM alias and final boot package remain unqualified.

During the combined-build source freeze, three additional files target-compiled: `backup_clock_mux_select_experiment.c` covers the complete native `0x100080f4` mux selector, `backup_clock_register_apply_experiment.c` covers the complete native `0x100035a0` register-record writer, and `backup_stage2_exception_experiment.c` covers the authentic nonreturn report/capture/default exception chain `0x100031f0..0x10003240`. The latter's disassembly matches the native CR reads, frame stores, and loops; its scratch word at `0x20017390` remains a typed BSS placement contract. Their MMIO hardware effects and record provenance have not been physically qualified.

`backup_stage2_clock_init_experiment.c` also target-compiles as a full CFG candidate for `0x10003294..0x100034b9`. It retains both wake-state paths, the 19 module selections, 13 common register configurations, 3 flag configurations, 10-record loops, 5-step trim/failure loop, gate-bit replay, and final MMIO clear. Its four direct code children `0x10003788`, `0x100038e8`, `0x100039f4`, and `0x10003b08` now have source-owned selected providers. RAM record producers remain explicit; target compilation does not prove physical behavior.

The `0x10003b08` child now also has a separately target-compiled C candidate, `backup_clock_state_refresh_experiment.c`. Its CK804EF disassembly preserves native volatile MMIO read/write ordering for the clock registers and an explicit ISA load from input address zero on the stock null path. The native zero-state early return was preserved after comparing the compiled CFG; no default value is substituted for an invalid state pointer.

`backup_clock_trim_apply_experiment.c` separately target-compiles the preceding native `0x100039f4..0x10003aff` replay with its finite 64-bit timer wait. It uses the already selected `0x10005070` time provider, multiplies the caller's timeout by 1000 with native 32-bit wrap, polls the status bit before each elapsed check, and returns the native zero or negative-one result. This remains source/ISA evidence, not a physical clock-settle timing proof.

After freeze release, all six clock/exception units were selected, and the pinned Grus divider/DTO wrappers were added to the already selected `backup_clock_module_select.c` so its private parameter table has one translation-unit owner. The separate target build `build-stage2-clock-round/receipt.json` is terminal: 248 source units, linked object SHA-256 `7e1798adfc4e06ac09bf3a71aad854ffa3749137f56ea6a1842c0c30fba22a12`, 16 genuine imports (12 data/BSS and four code). `source_complete` remains false.

At that snapshot, the SPI transfer callback `0x100082a8` and denoise tick `0x1000b958` still required full source reduction.
