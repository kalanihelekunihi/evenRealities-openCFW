# Ambiq MSPI upstream evidence

The three available files are byte-for-byte Git blobs from the public Ambiq `ambiqhal_ambiq` API tree at commit `5efc0228528a8adce5eae0d226fac85d2551eb3b`. For each file, the local length and calculated Git blob SHA-1 equal the corresponding API-tree entry; SHA-256 identities are recorded in `evidence.json`. The blob identity verifies these are exact public upstream snapshots. It says nothing by itself about which compiler, flags, or source revision produced a firmware code range.

## Source/API contract

`am_hal_mspi.c` lines 3990–4018 implement `am_hal_mspi_status_get`: after optional `AM_HAL_DISABLE_API_VALIDATION` handle checking, it obtains the module from state; reports DMAERR, DMACPL, and DMATIP into `bErr`, `bCmp`, and `bTIP`; copies the software-maintained CQ-entry count; returns success.

Lines 4025–4053 enable a caller-supplied mask by OR-ing it into that module's `INTEN`; lines 4060–4087 disable a mask by clearing those bits. Both conditionally reject invalid handles and otherwise return success.

Lines 4094–4127 read `INTSTAT` into the output, either raw or ANDed with `INTEN` when `bEnabledOnly` is true. Lines 4134–4161 clear the selected bits by writing `INTCLR = ui32IntMask`, then perform a volatile read of `INTSTAT`, and return success. These routines do not add a lock around register access; callers and interrupt concurrency remain part of the surrounding system contract.

The pinned `am_hal_mspi.h:60` defines `MSPIn(n)` as `((MSPI0_Type*)(MSPI0_BASE + n * (MSPI1_BASE - MSPI0_BASE)))`. Pinned `apollo510.h:29558–29560` sets bases to `0x40060000`, `0x40061000`, and `0x40062000`; the stride is `0x1000`, so module indices 0, 1, and 2 map to those bases. `am_hal_mspi.c` also includes `am_mcu_apollo.h` for surrounding MCU APIs/state, but that is not needed to resolve this macro. This mapping check is limited to the three listed module bases and does not establish a wider runtime index validation contract.

The clear attribution is pre-existing; this task adds no coverage or match count.
