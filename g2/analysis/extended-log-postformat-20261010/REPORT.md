# Extended logger postformat suffix

`postformat.c` source-defines the local suffix of direct logger `0x43d8dc..0x43d970`, entered after its prefix and branch-dependent appends. It invokes a variadic-format provider, bounds the shared buffer offset, applies the config-token filter, appends the optional suffix and newline with the previously validated non-null append primitive, invokes output, and exits the logger guard. The shared buffer is fixed at `0x2006bd30`; logger state is at `0x20070be8`.

`verify.py` compiles M55 and M4 with warnings as errors and links `postformat.c` with `append.c`. It compares stock suffix execution against source in **1,568** Unicorn fixtures covering four levels, seven initial offsets including 1018–1024, seven formatter returns including negative and oversized, filter enabled/disabled, match/no match, and optional suffix enabled/disabled. Ordered provider calls/arguments, 1,040 shared buffer bytes, final offset and stop PC match. There are three provider-call shapes. The original enters with a synthetic live stack frame; source uses explicit format and argument pointers. Lower format, filter, output and unlock callbacks are scripted; initialized logger state and actual transport effects are not claimed.

The 21-unit main archive now includes both this suffix and the fixed timestamp source. Its generated `g2/build/source-candidates/20261010-main/receipt.json` has four unchanged direct FlashDB undefined symbols. The direct logger remains 10/11 SMP bodies: the general variadic `0x44b76c`/`0x481836` contract and whole-body accepted-prefix integration/comparison remain. Fatal callback target and initialized shared state also remain external evidence boundaries.
