# Independent review: WSF timer cancellation and radio shutdown prefix

The bounded timer-cancellation implementation is consistent with the pinned public WSF source and the mapped stock data use. `WsfQueueRemove`, `wsfTimerRemove`, and `WsfTimerStop` are retained from the recorded Apache-licensed commit; the proprietary WSF critical-section port is reused from the existing reconstructed component. The sparse timer view deliberately assigns semantics only to `pNext` at offset 0 and `isStarted` at byte 13; the message/tick/handler bytes between them are opaque. Queue head and tail occupy the fixed 8-byte pair. The tested radio timer is at `0x20073E64`, queue at `0x200741B0`, and critical depth byte at `0x20075045`.

I independently ran 13 native Unicorn comparisons against the authenticated original and linked source module. Head, middle, tail, absent, nested, incoming-PRIMASK, and timer-to-GPIO phase samples matched the independent model. The broad recorded comparison currently reports PASS for 2,624 original/source/model cases and 500 unique original trace bytes.

The unlink logic preserves the removed node’s `pNext`, changes queue head or predecessor link only as appropriate, sets tail to the predecessor only when removing the tail, and clears the timer’s started byte only when the timer is found. An absent timer remains unchanged. The phase comparison begins with `WsfTimerStop`, then executes the GPIO shutdown prefix; it preserves the order before the previously reviewed GPIO-only slice.

The main operational caveat is inherited from the WSF port: its byte-depth critical section masks interrupts only on entry from depth zero and unmasks on the final exit without saving the incoming PRIMASK. Thus an incoming masked state can be unmasked, and byte-depth overflow can wrap. The verifier exercises overflow values diagnostically and the implementation report explicitly avoids treating them as safe. Valid ordinary nesting and the modeled input conditions pass comparison.

The evidence does not establish safe timer lifetime under concurrent expiry, timer allocation/free, expiration callback delivery, pending interrupt/NVIC cleanup, transport release, or whole-device shutdown safety. The timer queue fixtures are finite acyclic mapped queues; malformed predecessor cases are contract diagnostics. GPIO write-one effects remain simulator fixtures, not physical hardware behavior.
