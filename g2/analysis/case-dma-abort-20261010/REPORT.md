# CASE DMA abort providers, fixed G2 image

The authenticated CASE image is `g2-2.2.6.10/firmware_box.bin`, SHA-256 `36ca0c13558f252af286ae2b36b5e576d087d21d37b15d778e7da9f502a70374`. Stock `HAL_DMA_Abort` is `0x0800487a..0x080048e4`; `HAL_DMA_Abort_IT` is `0x080048e6..0x08004954`. The retained STM32G0 UART source identifies the two calls, but no pinned `stm32g0xx_hal_dma.c` was present in the retained local corpus. The source contract here is based on the complete fixed-image bodies and execution comparison, rather than assuming another HAL release is identical.

`dma_abort_provider.c` source-defines both archive imports. For synchronous abort, null returns status 1; a nonbusy DMA handle writes error `4`, unlocks and returns 1. A busy handle clears channel interrupt/enable bits, DMAMUX request and overrun state, writes channel and mux clear registers, sets state ready and unlocks, then returns 0. The IT body has no stock null guard; its nonbusy branch writes error `4` and returns 1 without unlocking. Its busy branch performs the corresponding register/state changes and invokes the installed `XferAbortCallback` **before returning** when nonnull. That synchronous callback invocation corrects the earlier selected IRQ fixture's deliberately modeled delayed completion; delayed hardware scheduling is not stock behavior of this body.

`verify.py` compiles the archive source at `-Os` for Cortex-M0+ and compares both complete stock entries with source in **194 fixtures**. It covers four initial DMA states, optional mux, optional callback, two lock bytes, three channel-shift positions, both sync/IT entries, and two synchronous null cases. It checks return status, all 96 DMA-handle bytes, a 192-byte MMIO window, ordered register writes and callback count/argument/state. The IT null input is excluded because the stock body dereferences it. `results.json` retains each case, hashes and traces. The fixture's register RAM is synthetic; peripheral electrical behavior and DMA timing are not asserted.

`verify_irq_native_dma.py` then compares the stock public UART IRQ with its **native stock abort bodies**, while the source path uses the archive's RX/error prefix, continuation, TOIDLE/tail leaves and newly source-defined abort providers. It passes **1,264 coherent cases** across error/RX/IDLE/tail domains. Only the lower TX-completion body remains a common compiled fixture in this comparison. `irq_native_dma_results.json` records source/ELF/image hashes and family counts.

The deterministic CASE archive now has **42 objects, 69 provided symbols and four unresolved imports**: direct `case_legacy_command` and `case_binary_command`, lower `case_tx_complete_provider` and `case_vformat`. Whole-archive relocatable link passes. Archive SHA-256 is `747d02408021ef275de05bc78f9ea5352a544f7c8025c6a8ddc1ba328ded8e6c`; relocatable SHA-256 is `53144226782d6f7b7f065bcb42aa8b52baf410c7877993f3848a09be7c5376df`. Direct CASE completion stays **10/12**. This does not establish a flashable image or physical DMA behavior.
