# Bounded SmpDbService candidate

**Completed:** one 146-byte direct SMP provider, stock 0x542960..0x5429f2, reconstructed as Cortex-M55-compilable C. The fixed stripped Apollo main image is authenticated at base 0x438000, SHA-256 `19044a72bdfeb04c6b1b104d87da7b98e13cc18928528d84d999b6bcc0ba9701`. Literal checks bind the ten-record table to 0x200708ec and configuration pointer cell to 0x200004b8. The original in-use and timer-start helper bodies at 0x541e50 and 0x541e34 establish row predicate and one-shot timer test; the source inlines their recovered behavior up to the explicit lower timer-start call at 0x52a4c4.

The verifier compiles Cortex-M55 and Cortex-M4 objects. It executes the original service and its real helper bytes in Unicorn, and compares them with the compiled Cortex-M4 candidate. **2,016/2,016 original-versus-source cases pass.** Fixtures cover empty/all-active/individual rows including first and last indices, seven combinations of activity and counter boundaries (0, 1, 999, 1000, 1001, 2000 and UINT32_MAX), divisors 0/1/3/1000, reload intervals 0/1/2000, timer-active byte 0/1, and a timer callback that either does or does not mark itself active. Row bytes, configuration bytes, timer-start arguments/order, proper return and SP are compared. Results and compile command are in `results.json`.

The lower timer-start provider is an explicit callback in both runs. These fixtures establish state transitions on synthetic records and provider call order; they do not establish initialized database contents, timer scheduling, clock frequency, concurrency or hardware behavior. A zero divisor is handled to match the observed ARM `sdiv` result; this does not make invalid configuration a supported device state. The context for this candidate still needs assembly with the SMP handler's other provider contexts and actual timer provider. No byte equality follows from semantic comparison.

**Direct-provider progress:** 8/11 SMP handler direct bodies now have local compiled source candidates. The remaining three are smpSmExecute 0x56ee62, extended log 0x43d574 and WsfTrace 0x52a63c. These include state-machine and formatting/trace dependencies; their completion duration and whole-firmware effort cannot be inferred from this bounded provider. Canonical `P2_EXECUTING` and G2-G6 gates are unchanged.
