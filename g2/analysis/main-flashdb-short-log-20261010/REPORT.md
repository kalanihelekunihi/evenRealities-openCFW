# FlashDB short event-logger provider

The Main FlashDB wrapper imports `g2_flashdb_candidate_compress` at stock `0x43ce9e..0x43cf02` (100 bytes). That stock body is an event logger gate, despite the older `compress` symbol label. It reads policy byte through `0x44a9ae`, rejects interrupt context through `MRS IPSR`, checks the lock-state word at `0x20074388`, merges the high ten bits of `r0` with the low 22 bits of `r1`, takes the lock with timeout 500, calls short formatter `0x43cb84` with the original `r2` format and a pointer to the first `r3` vararg, then releases the lock. Its public return is zero in every local branch.

`short_log_wrapper.c` is an isolated Cortex-M55 source body. The GNU ARM `va_list` register-save pointer is passed to the lower formatter, preserving register `r3` followed by stacked arguments. `verify.py` compiles the source and compares it with the fixed stock image for 324 combinations of policy 0/1/255, IPSR 0/3, lock absent/present, take result 0/1/2, token 0/all ones/FlashDB `0x04800000`, and category 0/max low field/mixed bits. The comparator checks ordered lower calls, lock and timeout arguments, merged token, format pointer, the first four variadic words and return/state. **324/324 pass.** Both stock and source `MRS IPSR` are intercepted only to supply the same synthetic architectural register because this Unicorn build rejects that instruction; all other local instructions execute. `receipt.json` carries the image/body/source/ELF hashes and exact build command.

This closes the bounded **local 100-byte provider body**, but it is not an end-to-end production logger. Policy, semaphore take/give, and short formatter are explicit lower boundaries. The short formatter has independent source evidence under `g2/analysis/audio-dsp-frontier-20261010`; its ring output/state and format-domain limits still apply. The FlashDB wrapper's own literal/database import, `get_blob`, and extended log `0x43d574` remain unresolved. Main direct SMP coverage stays **10/11** because the extended logger is a different body. Exact full-image equality has no estimate from this one body.
