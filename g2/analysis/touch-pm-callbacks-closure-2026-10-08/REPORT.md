## Interfaces and lifetime

Descriptor ABI: callback pointer+0, type byte+4, skip-phase masku32+8, parameter pointer+12, previous+16,next+20, orderbyte+24; size28 ARM32 bytes. Params contain base/context pointers. Selected public environment has static offset assertions and an explicit byte type representation. Caller owns descriptor, params and callback context; registration links the descriptor directly without copying or allocating. It rejects null descriptor/params/function and duplicate pointer. Tested valid types0/1, coherent allocated descriptors and acyclic lists. No type/range safety for arbitrary inputs is claimed.

Roots are SRAM20000f34 indexed by type. Registration sorts ascending order; equal orders retain registration order. Reverse traversal reverses that registration order. Null root inserts and clears links. Existing insertion updates adjacent previous/next pointers; duplicate rejects without modifications. No removal source is reconstructed here: stock has RegisterCallback immediately followed by ExecuteCallback; a matching stock UnregisterCallback body was not identified in this scoped dependency chain. Registration is not safe evidence for freeing descriptors while still linked.

## Phases, errors and cancellation

Phase1(CHECK_READY) and4(BEFORE_TRANSITION) traverse forward. A callback runs iff its skip mask does not contain the phase. Params are copied to a local stack object before invocation. Each invoked callback replaces the accumulated return value and updates **one shared lastExecutedCallback at20000f24**, across callback types. Phase1 halts only for exact0x4200ff(FAIL), not every nonzero error. Failed pointer arrays at20000f28 are set to that last callback on exact failure, otherwise cleared. Skipped callbacks do not update last.

Phase2(CHECK_FAIL) starts at the predecessor of the shared last callback, deliberately skipping the callback that failed. Phase8(AFTER_TRANSITION) starts from the list tail and walks backward. Reverse phases keep traversing despite failures and return the final invoked callback's status. Calling phase2 after successful phase1, or interleaving types before cancellation, is not equivalent to a correctly paired transaction. The explicit synthetic interleave type0-ready→type1-ready→type0-cancel visits a type1 predecessor because last is shared. This is a **caller-serialization requirement**, not a demonstrated firmware race.

Supported empty-list phases1/2/4 return0 with initial last=NULL. **Phase8 dereferences cur->next without checking the root for NULL** in original/public code. It is excluded from the supported contract. The full DeepSleep wrapper checks root before executing any phase, so its ordinary empty-list path avoids this dereference. Invalid type/mode assertion paths are excluded; public assertion macros are explicitly disabled only for valid supported test inputs.

## Concrete boundary

Physical counter readiness/frequency, WFI wake source/interrupt delivery, post-wake clock/peripheral restoration and concurrency remain unverified. Needed input is a timestamped device/peripheral trace covering SRSS counters, PRIMASK, pending wake/IRQ, WFI return and callback phases, or a faithful Cortex-M0+/MSCLP/SRSS interrupt-and-sleep model.
