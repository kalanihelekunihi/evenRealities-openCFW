The DLIB runtime environment

In this section:

This section describes the DLIB runtime environment in which an application executes. It covers how you can modify it by setting options, overriding default library modules, or building your own library. The chapter also describes system initialization introducing the file cstartup.s, how to use modules for locale, and file I/O.
