# Radio GPIO interrupt consumer

This read-only packet traces the authenticated registration for GPIO 117, its callback, the `GPIO0_607F_IRQHandler` service path, NVIC setup, and the directly supported shutdown boundary. The authoritative outputs are [results-final.json](results-final.json) and [disassembly-final.txt](disassembly-final.txt). Run `~/.local/share/opencfw/venv/bin/python verify.py` to verify image mapping, body hashes, selected direct calls, and literal words. Earlier `results.json`/`disassembly.txt` and `results-complete.json`/`disassembly-complete.txt` remain preserved; use the `*-final` files for the latest checked packet.

The evidence is bound to official `g2/blobs/official/g2-2.2.6.10/ota_s200_firmware_ota.bin`, SHA-256 `36c5b0e499a68ac2493a497bdab9740fd3e7027730c26a9094eca47268a27863`; its 32-byte OTA preamble is excluded from the Ghidra image at `0x438000` (SHA-256 `19044a72bdfeb04c6b1b104d87da7b98e13cc18928528d84d999b6bcc0ba9701`). The principal function bodies and authenticated hashes are in the JSON.

`HciDrvRadioBoot` (`0x4b48a6`) resets the callback counter at RAM `0x20074640`, then—regardless of its optional nonzero-only configuration branch—registers channel 0, pin 117, callback `HciDrvIntService` (`0x4b4a98`), argument 0. At `0x4b49b6` it calls `0x52dd58`, whose exact instructions put pin `0x75` on the stack and call GPIO interrupt control `0x4810b0` with channel 0 and control value 1 (`INDV_ENABLE`). The GPIO handler/argument table for pin 117 is row 3, bit 21, at `0x200683fc` and `0x20068afc`. Boot then calls the priority wrapper with IRQ `0x3b` and value 4, followed by the NVIC set-enable wrapper for that IRQ. The wrappers write byte `0x40` at `0xe000e43b` and word `0x08000000` at `0xe000e104`, respectively. The cached Apollo510 header names IRQ 59 `GPIO0_607F_IRQn`.

The paired `0x52dd6a` helper used by `HciDrvRadioShutdown` supplies the same channel and pin with control value 0 (`INDV_DISABLE`). The authenticated `0x4810b0` body (`[0x4810b0,0x4812f6)`, 582 bytes, SHA-256 `be21713c06a339f82b208a72294f0c9d573a7822128b69e06ae5a4fe2770f5a6`) maps pin 117 to GPIO word index 3 and bit 21, and updates the channel-0 EN word at `0x40010560` under PRIMASK save/restore. The cached Ambiq API is `am_hal_gpio_interrupt_control` in `g2/build/foundation/ambiq-upstream/am_hal_gpio.c` (release marker `release_sdk5p1p0-366b80e084`; source hash recorded in JSON); its GPIO control enum defines 0 as individual disable and 1 as individual enable.

`GPIO0_607F_IRQHandler` (`[0x4b80be,0x4b80ea)`) first calls `0x4812f6` for an all-seven-word channel-0 status snapshot into a stack buffer. It then reads IRQ `0x3b` status with enabled-only false, clears the returned mask, and dispatches that same mask through `0x4816c6`. It ignores each helper return value; the initial seven-word snapshot is not consumed later in this ISR body. The callback service maps the IRQ to row 3 and visits pending bits in ascending bit order. A pending pin-117 bit therefore dispatches the registered function with argument 0; other bits depend on their own callback-table slots.

`HciDrvIntService` increments the 32-bit counter at `0x20074640`, loads a byte event identifier from `0x20074fcb`, and calls `WsfSetEvent` at `0x52b91e` with `(event_id, 1)`. The authenticated 64-byte `WsfSetEvent` body enters/exits its WSF critical section, sets bit 0 in the event-id-selected byte (`eventId & 0xf`, offset `0x28`) and sets bit 2 at offset `0x3c` in its event state, then calls `WsfSetOsSpecificEvent`. The callback's return value is unused by the GPIO service.

For shutdown, the direct body stops the WSF timer, disables GPIO 117 through `0x52dd6a -> 0x4810b0`, then performs additional radio/GPIO operations, zeros two radio ring counters, and calls a radio-side operation. Its authenticated body has no direct callback-unregister call and no direct NVIC priority or NVIC enable/disable wrapper call. The known callers include `appBleStart`, `HciDrvHandler`, and `hciCmdTimeout`; several paths call boot again after shutdown. This packet establishes the direct shutdown path and GPIO117 disable, not the transitive effects of every out-of-scope callee or final hardware state.

The local source snapshot contains Ambiq redistribution terms and notices. The source comparison supports API semantics; it does not prove compiler-byte identity or the runtime contents of callback/event state. No GPIO/NVIC hardware or WSF scheduler was executed.
