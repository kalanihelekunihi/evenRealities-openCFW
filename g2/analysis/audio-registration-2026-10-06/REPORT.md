## Observer boundary

Registration comparisons use **no memory hooks**. A code-derived observer decodes executed instructions and pre-instruction registers to reconstruct normalized ordered store bytes for registry, queue/data, handle/counter/critical word, I2S and SCB addresses. Normalization compares ordering/values, not scalar versus multiword atomicity. The final snapshot compares every mapped RAM byte except stack2000e000..2000f000 and the two explicit source observation outputs; it also compares complete modeled I2S0 and SCB pages and final interrupt masks.

A10-call queue-full/FIFO/DMA-partial-busy/cache-handoff/PCM prefix sequence is repeated with no memory hooks and with the previous scoped memory observer. Cuts, derived stores and final snapshots agree between profiles and between authenticated original and source. Independent review repeated this audit and lifecycle comparisons. This checks that excluded queue/stack memory hooks did not hide functional changes on these paths. It is not a universal hook-equivalence claim, a read-trace audit for every address, or hardware MMIO/cache/coherence evidence. The older broad-hook skipped-load and optimized tick failures remain preserved and unaccepted; neither supplies coverage credit here.
