# Independent review: PCM registration lifecycle

**Disposition: accepted with bounded limits.** I reviewed the C source/header, current linked ELF, 103-call original/source result, original disassembly and caller literals, and the no-memory-hook observer-audit method. I independently reran nine registration/lifecycle checks and repeated the ten-call no-memory-hook versus scoped-memory-hook audit. The representative run passed.

The registration code follows the observed low-byte row calculation, guard, replace/clear/publish order, owner check, and unchecked unregister addressing. The actual memset body’s store order is reflected in the source, while the report correctly avoids claiming that three C stores have the same atomicity as the stock grouped store. The current source uses `FLAGS` as a `volatile uint8_t` macro at each test; the O2 ELF contains separate LDRB instructions for successive tests. I additionally changed flags from 0 to 1 synthetically between the first and second read; original and source both reached the `0x43ce9e` logger boundary. This is a test fixture, not evidence of a real concurrent writer.

Authenticated caller literal checks confirm the documented variants: codec init `0x58f69a` registers owner `0x10b`, mode 0 with callback `0x58f5e1` on its variant-0 path or `0x58f4e5` on variant 1; PDM init `0x58f7b0` registers owner `0x10b`, mode 1 with callback `0x58f5e1`. Their routes to the diagnostic file sink are static attribution, not executed callback/lifetime evidence.

The observer audit derives ordered store bytes from the executed instructions and pre-instruction registers, then compares full mapped RAM except the live stack and explicit observation outputs, plus complete modeled I2S and SCB pages and masks. The retained trace contains no predicated stores that would invalidate the store-event derivation. Repeating the ten-call lifecycle with no memory hooks and the scoped hooks produced matching cuts, store streams, and final snapshots. This is bounded evidence for those paths; it is not a universal read-trace audit, live hardware MMIO behavior, multiword atomicity, or concurrent registration safety.

The full comparison passes 103 calls and traces 1,736 original bytes. Logger-enabled cases stop before `0x43d574` / `0x43ce9e`; no fake logger returns are used. Callback/DSP/file providers, task wake/routing, and PCM ownership remain outside execution scope. No source or evidence defect blocks this bounded result.
