# Restricted whole-path SMP logger composition

`quiet.c` composes an **entry-to-return** source path for stock extended logger `0x43d574..0x43d976` under explicit synthetic state preconditions: `state[240]=0` (default module policy 5), `state[1]=0` (empty module filter), all normal-level category masks zero, `state[245]=0` (no color/prefix suffix), and `state[32]=0` (no output token filter). Its format pointer must be one of the two authenticated smpSmExecute literals. It performs the entry enable/level checks, enters the guard, and invokes the validated postformat suffix, bounded SMP format and append sources. Lock and output calls remain explicit callbacks.

`original_probe.py` first executes both SMP formats through the **stock complete logger entry**, reaching output and unlock without traps under this RAM fixture. It records a 28-byte named-state line and a 30-byte numeric-state line. `verify_quiet.py` then compiles the composed source for M55 and M4 with warnings as errors and compares **144** stock-entry/source-entry Unicorn fixtures across two formats, enabled/disabled logger, three global limits, six normal levels, and three numeric argument pairs. Ordered lock/output/unlock calls, their output arguments, all 1,040 shared-buffer bytes, return PC and stack restoration agree. `quiet_results.json` records hashes and two call shapes.

This is **not** a complete source definition of all 1,026 bytes. Remaining local branches include nonzero category masks (prefix level/module/tick/date/time selection), color suffixes, output token filtering in the full entry frame, level-six fatal callback/recursive nonreturning behavior, and module policy entries other than the default. The two validated SMP formats also do not cover arbitrary callers of `0x43d574`; general `0x44b76c` varargs semantics remain outside this candidate. `quiet.c` has a narrower four-argument adapter ABI than the stock logger's registers plus stack varargs; a full body would need the exact original call ABI, including the live argument pointer at `SP+80` after its prologue.

The next discriminating experiment is a stock-entry fixture matrix with one category bit enabled at a time in `state + 216 + 4*level`, toggling `state[245]` and output-token bytes at `state[32]`, while instrumenting the prefix append calls and time providers `0x44aaa8`, `0x44ab14`, `0x44ab1c`. It should compare the full shared buffer and lock/output call sequence with a source prefix implementation, then repeat for module-policy table rows and the bounded fatal stop. This is required before direct-body credit. The 23-unit main source archive includes `quiet.c`; direct SMP completion remains **10/11**.

## One-bit matrix follow-up

`mask_probe.py` now executes **54 stock-entry** fixtures: category bits zero, 1, 2, 4, 8, 16, 32, 64, 128, each with color on/off and output-token absent/matching/rejecting. Synthetic RAM tables at `0x20000974` and `0x2000098c` supply valid level/color strings. Without those table pointers, a color fixture reaches the stock appender's null-argument fatal recursion; this is an initialized-state dependency, not a source mismatch. `mask_probe.json` retains each call trace and first 160 shared-buffer bytes.

`onebit.c` source-composes the same entry-to-return path with the validated append, length, timestamp, token, SMP format and postformat lower units. `verify_onebit.py` compiles M55/M4 and compares all **54 original/source fixtures**, including full 1,040-byte shared buffer, ordered lock/time/output calls, output arguments and restored stack. All pass with eight call shapes. This is still bounded to a single category bit or zero, default module policy, empty module filter and the SMP format. Multiple-bit delimiter interactions, nondefault module policy rows, fatal path, and general caller formats remain to validate. The **24-unit** archive includes the one-bit source. Direct SMP completion stays **10/11**; the remaining local work is combined-bit matrix plus policy/fatal branches and original ABI composition. The fatal callback target and initialized production state remain external evidence limits.

## Module policy, filters, and stock call ABI

`extended-log-module-policy-20261010` validates the non-null five-row policy scan in **360** original/source comparisons. `onebit.c` now calls that source and the validated token search before entering the output guard. `verify_onebit.py --policy` adds **576** stock-entry/source-entry comparisons with disabled/default policy, matching rows at levels zero and three, a nonmatching row, empty/matching/rejecting module filters, both SMP formats, selected masks, color and output token states. All pass with nine call shapes.

`abi.c` supplies the stock eight-argument ARM call layout for the two authenticated SMP formats: `r0..r3` are level/module/file/function; stack words are line/format/arg0/arg1. Its provider table is explicitly bound by `g2_log_candidate_bind_smp_providers`. `verify_onebit.py --abi --policy` passes another **576** comparisons using identical stock entry registers and stack arguments on both sides. `--abi --all-masks` passes **1,536** more across every mask and color/token state. This validates the stock ABI for exactly two format arguments, not an arbitrary variadic call. The 26-unit main archive includes module policy and the ABI adapter.

The direct logger remains **10/11**. Remaining body breadth is level-six fatal callback/recursive nonreturning control flow, null module fatal behavior, and general format strings/argument counts from other callers. The accepted SMP normal-level path is bounded by synthetic policy/color tables; initialized production RAM and output transport remain separate evidence requirements. A next experiment should enumerate actual direct callers' format literals and argument counts, then test each against `0x44b76c` with original/source output. If the set is not finite and evidenced, a general formatter contract is required before claiming the whole direct logger.
