# Bounded WsfTrace wrapper and remaining SMP frontier

**Completed:** 54-byte WsfTrace wrapper at 0x52a63c..0x52a672 for the SmpHandler call shape. The fixed stripped main image has base 0x438000 and SHA-256 `19044a72bdfeb04c6b1b104d87da7b98e13cc18928528d84d999b6bcc0ba9701`. Original disassembly shows a 1024-byte stack buffer, format call 0x473036, first print 0x4733ee, threshold at 1024, optional WsfAssert 0x569a44 with line 137 and file literal 0x006df094, and final newline print using stock literal at 0x52a674. The source preserves this call order and threshold.

Clang compiles Cortex-M55 and Cortex-M4 objects. Unicorn executes original Thumb and compiled Cortex-M4 source with identical scripted formatter, print and assert providers. **120/120 comparisons pass** across two format identities, two argument triples, six synthetic formatted lengths (including 1023/1024/2048), and five first-print return lengths (including 1023/1024/2048). It compares provider call order, argument words, emitted buffer content and both assert branches, plus proper return and SP. Results and compile command are in `results.json`.

This is a complete bounded **wrapper** at explicit lower provider boundaries. Formatting at 0x473036, output at 0x4733ee and WsfAssert effects remain unsourced and scripted in this test. It does not establish full logger output, actual format-string behavior, device trace routing or handling of arbitrary extra varargs beyond the SMP call. The candidate context must be assembled with the handler's other provider contexts.

**Direct SMP tally:** 9/11 direct bodies have local compiled source candidates. The remaining two are extended log 0x43d574..0x43d976 (1,026 bytes) and smpSmExecute 0x56ee62..0x56f144 (738 bytes). A static scan of the retained complete disassembly finds 380 decoded lines and 59 direct/indirect call sites to 19 distinct syntactic targets in extended log, including a recursive/fatal path and an indirect callback; smpSmExecute has 293 decoded lines and 48 call sites to nine distinct targets. These figures are reconnaissance, not behavioral coverage or an exhaustive dynamic dependency count. Their logging configuration, formatting and state-machine providers need bounded source and branch fixtures before either body can be counted complete. At least these two direct bodies and the trace formatter/output/assert lower chain remain; a credible whole-protocol or firmware duration estimate is unavailable.

Canonical `P2_EXECUTING` and G2-G6 gates are unchanged. No whole-SMP source completeness, byte equality or hardware trace behavior is claimed.
