# Bounded WSF queue provider chain

**Completed source bodies:** WsfCsEnter 0x52b8a4..0x52b8b6 (18 bytes), WsfCsExit 0x52b8b6..0x52b8c8 (18), WsfQueueDeq 0x538c4a..0x538c6e (36), WsfMsgDeq 0x4bf9ec..0x4bfa00 (20), and WsfMsgFree 0x4bf9b0..0x4bf9ba (10). These five bounded bodies total 102 original bytes. The fixed stripped Apollo main image has base 0x438000 and SHA-256 `19044a72bdfeb04c6b1b104d87da7b98e13cc18928528d84d999b6bcc0ba9701`; `verify.py` checks the SHA and literal 0x52bab8 -> WSF nesting byte 0x20075045.

The source compiles with Clang for Cortex-M55, and a separate Cortex-M4 object is executed in Unicorn against original stock bytes. The verifier compares five entry points over four queue lengths, four WSF nesting values (including wrap at 255), and both incoming PRIMASK states: **160/160 comparisons pass**. It checks return values where defined, all queue head/tail words, handler ID, nesting byte, PRIMASK, unchanged node bytes, restored SP, and the exact hidden-header argument sent to WsfBufFree. Original WsfCsEnter/Exit execute; their IRQ mask changes are compared against source. Both sides intercept only the lowest allocator call, at stock 0x5304d4 or the compiled callback target. `results.json` records source and compile provenance.

The source is grounded in the complete stock disassembly and previously retained SDK5.2 Apache Cordio WSF message/queue sources under `g2/analysis/source-discovery-parallel-2026-10-09/smp-stale-queue-20261010/`. Existing five stale-queue fixtures establish wrapper call order. The separate `g2/components/foundation/freertos_daemon/task_critical.c` uses FreeRTOS nesting and BASEPRI, so it is not substituted for the WSF CPSID/CPSIE byte-nesting contract. `g2/components/foundation/freertos_queue/` is also a different queue family.

Of SmpHandler's 11 unique direct providers, the two WSF message wrappers now have compiled bounded source in addition to the three prior logging/comparison getter candidates: **5/11 direct provider bodies have local source candidates; 6/11 remain** (SmpDbService 0x542960, WsfBufFree 0x5304d4, smpCcbByConnId 0x5375fc, smpSmExecute 0x56ee62, extended log 0x43d574, WsfTrace 0x52a63c). WsfQueueDeq and WsfCsEnter/Exit are now locally source-defined lower dependencies. The buffer allocator is not counted complete: its original 62-byte body depends on live pool table pointer 0x20074eec, pool count byte 0x20075044, free-list heads, and object lifetime. The available original-byte tests intercept it, so they do not establish pool recycling or safe ownership. A source-defined WsfBufFree requires validated initialized pool layout and allocation/free lifecycle fixtures.

This is synthetic queue and interrupt-mask execution in Unicorn, not hardware concurrency or a production allocator. The shared SMP callback context and relocatable literal/data mapping remain integration tasks. Canonical `P2_EXECUTING` and G2-G6 gates are unchanged; neither whole-firmware source completeness nor byte equality follows.
