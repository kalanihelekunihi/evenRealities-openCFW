Manager setup source matches the examined routines: event creation writes the event handle to `0x20000510`; setup initializes event runtime and dispatches the manager callback at slot `0x200004CC`; callback dispatch sets the current manager task to priority 8, calls the slot, then sets it to 48. The setup flag wait uses the DFU task handle at `0x200004D4`, sets flag `0x800000`, computes `1 << bit` using ARM's low-byte register-shift behavior (shift >=32 yields zero), waits on the event with options 1 and timeout 20,000 raw ticks, then checks `(return & requested_mask) == requested_mask`. Consequently a high-bit return such as `0xFFFFFFFF` satisfies a requested low bit if it contains that bit; it is not treated as failure merely because bit 31 is set. The failure log uses the low byte of the original bit argument.
