Latest

v4.6
----

Key feature changes
^^^^^^^^^^^^^^^^^^^

* **Channel Assessment Central support**

  * Added support for Channel Assessment Central, enabling the central role to assess radio channel quality and improve behavior in noisy 2.4 GHz environments.
    In this initial version, the feature is enabled by default in Central sample projects, applies to ACL and CIS links only, and is transparent to the application (no additional configuration required).

* **Watchdog and IRQ priority management**

  * Modified the watchdog interrupt task priority to ensure the watchdog has the highest priority in the system.
  * Updated IRQ priority assignments across system components to align with the new interrupt priority scheme.

* **Linux SDK support**

  * Added Linux SDK support, including SDK content installation, scripts and documentation updates.

* **ESL and PAwR enhancements**

  * Enhanced the ESL and PAwR sample applications and stack integration, including improved ESL AP and Tag behavior, support for multiple ESL groups through multiple subevents, PAwR validation targets, and improved use of the dedicated PAwR library.

* **BLE sample application improvements**

  * Added new BLE sample applications, including EMB Error Handling and Hybrid Advertising, and improved existing applications such as ANCS Client, EMDT Data Transfer Server, ESL AP/Tag, PAwR Advertiser/Synchronizer, PAST Central, Tag, and Watch.

^^^^^^^^^^^^^^^^^^^

* PAwR feature is now  operational and stable. Recent updates have resolved key issues, enabling:

This SDK version comes with the following qualified Bluetooth features:

* **LE Advertising Extensions (5.0)**

  * Enables longer advertising messages, allowing more information to be conveyed, and supports multiple advertising channels.

* **Periodic Advertising Sync Transfer (5.1)**

  * Facilitates synchronization between a scanner and an advertiser, enabling the scanner to receive periodic advertising packets at the correct time.

* **LE Power Control (5.2)**

  * Dynamically adjust the power level of advertising and data transmissions based on the link quality and data rate requirements, minimizing power consumption and extending battery life.

* **LE Enhanced Connection Update (5.3)**

  *	Introduces new connection parameters, such as minimum connection interval and maximum latency, that provide fine-grained control over the connection, improving responsiveness and reducing latency for time-sensitive applications.

* **Connection Subrating (5.3)**

  * Enables faster switching between low and high duty cycle connections, allowing for more efficient data transfer and reduced latency for applications that require real-time data transfers.

* **LE Periodic Advertising with Response (5.4)**

  * Introduces a new type of periodic advertising that allows a device to act as a server, receiving responses from clients that are interested in its periodic advertisements.
