Release Notes

This section lists the new features, improvements, and major changes related to em_mltk.

To check the current version, run:

python -c "import em_mltk; print(em_mltk.__version__)"

Latest

V1.1.0

libem_ml_em9305: 0.2.6

This release introduces major updates and improvements, particularly in the area of quantization and related optimizations. As a result, it is not backward-compatible with previous versions. Please ensure that only files from this release are used.

Key Changes and Features

  • Upgraded support to TensorFlow 2.21 (previously 2.19).

  • The generated model is now provided as a C-compiled library.

  • All em_mltk support files are consolidated into a single static library: libem_ml_em9305.a.

  • Added support for 8-bit integer (int8) model quantization using TensorFlow Lite post-training quantization techniques.

  • Enhanced tensor definitions to support quantized data.

  • Added support for input/output data types: float32, int8 (new), and uint8 (new).

  • Refactored memory management to improve efficiency and support quantized models.

  • Reworked profiler output to provide more detailed insights into model performance.

  • Introduced an HTML report for profiler results.

  • Model input and output tensors are now declared in alphabetical order.

  • Improved logging for better readability.

  • Updated Jupyter notebooks to reflect new features and changes.

  • Updated the em_mltk_mnist example project to include a quantized model.

  • Added new layers:

    • Unstack

    • Split

Added a new Jupyter notebook example for gesture recognition.

V1.0.1

libem_ml_standard_em9305_main: 0.1.5

First official release of em_mltk. It contains the following features:

  • It suppports EM9305 device.

  • It converts a TensorFlow Lite model into a C source file for embedded systems.

  • It generates a complete model as C code for EM9305 BLE controller.

  • It generates a ready to use EM9305 project with CMake build system and 4 compilation targets: (None (default, Production), _TEST, _PROFILER, _EMPTY)

  • It supports these Keras Layers:

    • Add

    • AveragePooling1D

    • AveragePooling2D

    • BatchNormalization

    • Concatenate

    • Conv1D

    • Conv1DTranspose

    • Conv2D

    • Conv2DTranspose

    • Dense

    • Dropout

    • Flatten

    • GlobalAveragePooling1D

    • GlobalAveragePooling2D

    • GlobalMaxPooling1D

    • GlobalMaxPooling2D

    • Input

    • MaxPooling1D

    • MaxPooling2D

    • Multiply

    • Rescaling

    • Reshape

    • Stack

    • Subtract

  • It supports these Keras activation functions:

    • ReLu

    • Sigmoid

    • Tanh

    • LeakyReLU

    • Softmax

    • Swish (or SiLU)
