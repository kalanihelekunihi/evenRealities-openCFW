## A real reconstruction correction

The expanded root fixtures found a missing register15 restore when EXTREF is set and PLL is clear (flags `0x10`). Original `0x41af84..0x41afbc` tests EXTREF first and only consults PLL/FREFSEL if EXTREF is clear. The correct condition is:

```c
if (extref_needed || (pll_needed && pll_frefsel))
    power_register_update(15, saved_pin_configuration);
```

The previous C condition incorrectly required PLL in both cases. [Before-fix comparison](clock-extref-before-fix.failure.json) preserves the omitted restore; the source component is corrected. Candidate3522's earlier14/1,024-expanded cases did not exist at its validation time: its13 native-clock and896 carry cases remain preserved bounded receipts, not general correctness claims. Candidate25a13 includes the correction and expanded14 native/1,024 carry cases.
