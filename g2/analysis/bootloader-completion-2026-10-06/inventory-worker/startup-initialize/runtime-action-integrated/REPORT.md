## Ownership and error semantics

Stock416200 is the CMSIS termination wrapper: context failure returns-6, null handle-4, deleted task-3, otherwise native deletion and0. ItsR1 carries incomingR3. Native task state inspects currentTCB, state/event list membership and notification byte. Noncurrent deletion unlinks state/event items, decrements task count, refreshes unblock state and releases storage. Self deletion places the TCB on the termination list and increments pending-delete count; an active scheduler requestsPendSV. Ownership byteTCB+0x6d selects stack+TCB free(0), TCB-only free(1), or no free(2). Invalid ownership/configuration reaches an interrupt-masked invalid-address assertion boundary. The task wrappers clear their stored handle even on termination errors. These tests explain this behavior; they do not establish leak/safety behavior on hardware.
