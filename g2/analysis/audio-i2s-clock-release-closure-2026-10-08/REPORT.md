# Last-client clock release and power command

**88 PASS comparisons**:24 direct power-command and64 group4 client-release cases. [Independent C](../../components/audio/i2s_clock_release_offline/clock.c), [results](results.json), [instructions](original-disassembly.txt), [provenance](provenance.json).

The preceding [I2S stop batch](../audio-i2s-stop-closure-2026-10-08/REPORT.md) stopped last-client cases before `0x4D391E`. This successor executes that complete provider: it narrows input to uint8, sets bit0 of **`0x40004044`** according to whether that byte is nonzero, preserves other bits, and returns0. Input0 clears the bit. **There is no status poll, delay, DMA acknowledgment or callback in these 26 bytes.** A command write and stock return do not establish physical completion.

Original `0x4C4016` checks peripheral membership in software clock-group4 at `0x20073344` (two words). If absent it returns0 without power write. If present, it calls actual save/disable-IRQ `0x473940`, clears membership and, only when both words are zero, issues `0x4D391E(0)`. It restores prior PRIMASK and returns0. Independent C implements these reads/stores/power command with the same real IRQ-save peer. Tests cover peripheral29/30, client/other-client combinations, initial PRIMASK0/1 and four power-register patterns. Direct command cases cover0/1/2/0x100/0x101/0xFFFFFFFF, verifying low-byte narrowing. Ordered writes, client table, result and restored PRIMASK agree; release-time power write is verified under PRIMASK1.

All register state is **passive synthetic MMIO**, with no power-domain transition, clock stability, DMA engine or interrupt delivery. This closes the software provider boundary, not physical quiescence or the entire stop caller's last-client continuation. Other clock groups, source-changing reconfiguration, broader power-control `0x590648`, and live lifecycle scheduling remain separate available dependencies.
