## What the generator chooses

The postdivider function0x539794 calls min-VCO0x539674 twice, with60,000,000 and240,000,000Hz minimums. If target<minimum it computes ceil(minimum/target), rejects required divisors>=50, then uses a50-byte nibble-pair lookup to select the smallest supported postdivider product. This is scalar configuration data, not an executable array. VCO is target*post1*post2 in wrapping32-bit arithmetic. Base generator prefers integer mode, normalizes feedback below4, and otherwise tries fractional feedback with24-bit fractional scale.

Valid candidates are scored using fourA/B weights indexed by fractional/integer mode and low/high VCO. Score arithmetic is uint32 with multiplication/addition wrap, not a floating cost or guaranteed physical optimization. Lower score wins; ties choose the high-minimum candidate. With reference12MHz,target48MHz the selected output is mode1/refdiv1/post5/1/feedback20/fraction0: nominal240MHz VCO. Reference byte is preserved by the generator; manager supplies external-reference1. This reproduces stock config `010101010501140000000000` when that byte is1.
