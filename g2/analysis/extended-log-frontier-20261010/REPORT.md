## Current closure audit (2026-10-10)

The later retained source/original receipts narrow that frontier. The 27-unit Main archive includes guard, policy, append, output, memory, token, timestamp, postformat, module-policy, bounded formatter, and SMP entry adapters. The whole-entry SMP tests include 1,536 all-mask/color/token cases, 648 level cases, 576 module-policy/filter cases, and 1,536 stock-ABI all-mask cases (`extended-log-whole-smp-20261010`). These are overlapping fixture families, not an additive count of unique firmware states. The bounded integer/string formatter comparisons cover 336 basic, 196 width, and 96 additional conversion cases; five selected one-, three-, and four-word whole-entry call layouts have 720 comparisons (`extended-log-common-format-20261010`). These receipts support only their stated format and initialized synthetic-state preconditions.

Of 6,239 syntactic direct calls, 6,227 resolve to flash format literals at 5,032 distinct addresses. The static parser accepts tokens at 6,209 sites; this is a syntax screen rather than behavioral or argument-layout proof. The 18 excluded static sites use float syntax. Twelve sites pass runtime format pointers: four receive wrapper parameter R8 and eight point to a constructed stack hex buffer (`extended-log-caller-inventory-20261010`, `extended-log-float-runtime-20261010`). Thus the remaining **direct body count is one** (10/11 SMP direct bodies); lower format and producer breadth remains open and has no finite source-body count from this inventory.

The fatal tests stop at callback entry or the first nonreturning loop call. They establish assertion line 481 for null module and 572 for level six, but do not establish an installed callback target, its return behavior, or productive continuation. The available Unicorn M4/M7/M33 models stop at stock `vmul.f64` at 0x4d435c. QEMU M55 executes standalone FP64, but its tested MPS3 AN547 map cannot host the original image at 0x438000. Ghidra currently has no running instance; retained disassembly and receipts are the available oracle. No full-body C source or archive change is warranted from these observations.

The next discriminating work is (1) an address-compatible FP64 original-byte execution fixture for representative nonzero `%f` values and destination capacities, (2) caller-producer/argument-layout comparisons for each of the 12 runtime-pointer sites, and (3) a proven callback target/state or bounded full-handler trace through callback return for fatal/null-module inputs. Separately, representative accepted call layouts beyond the five measured formats are needed before a general variadic bridge is claimed. Completion time cannot be inferred from syntactic call counts; these four evidence areas are the remaining bounded estimate, and output transport plus initialized production RAM are separate image-level dependencies.
