# ISR semaphore and queue source closure

**Four new bodies** are exercised in recovered native source: ISR receive0x441DA6, ISR semaphore give0x441A42, CMSIS semaphore acquire0x44994E and release0x4499B8. The private copy helper, task take/send and list/wake/mask providers are reused. **392 original-instruction comparisons PASS** against one exact receipt-bound final ELF. Valid queue payloads0,1,4,12,205 bytes, lock/task-count limits, wake-pointer null/initial state, priorities46/47/54, suspended scheduler, masks/IPSR/pre-start context, full/empty/null queues and task-yield cuts are exercised. Independent count/status/payload/mask invariants accompany original/native equality. Native reached-PC guards exclude original executable fallback; zero unresolved symbols. Tests step unmodified original instructions because of the already documented continuous-Unicorn IT-state anomaly.

ISR receive copies item-size bytes out before relinquishing a queue slot; semaphore item size0 needs no payload buffer. ISR give only adds availability and forbids a held mutex. Unlocked queues process waiters; locked queues increment deferred Rx/Tx counters capped by task count. A null wake pointer suppresses publishing the wake flag, not list movement. Existing nonzero wake-flag values are not automatically cleared by the kernel.

CMSIS wrappers initialize local wake flags, restore interrupt masks through native providers, and request PendSV on successful higher-priority wake. Null semaphore returns-4 even in IRQ-style context. IRQ-style acquire rejects positive timeout with-4, whereas mutex acquire rejects IRQ-style calls with-6. Task waits use ticks; there is no proven millisecond conversion. Positive task waits stop before actual port yield. PendSV requests are observed software writes, not delivered interrupts or task handovers.

No physical device, firmware patch or new lifecycle safety assertion. MMIO and scheduling state are constructed. The selected task/ISR semaphore ownership interface has source providers through its handover boundary; real resumed timeout completion still needs coherent task/exception trace or a validated scheduler model. Adjacent CMSIS memory-pool alloc0x449D3E now has source-backed task/ISR semaphore dependencies, but pool record/free-list construction remains an actionable separate public-source lead. Broader whole-image source inference is not exhausted.
