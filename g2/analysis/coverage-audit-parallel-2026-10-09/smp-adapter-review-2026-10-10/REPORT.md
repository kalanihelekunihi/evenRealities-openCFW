# Independent SMP adapter and execution contract review

Adapter accepted for bounded instruction/address evidence. [Six independent checks](receipt.json) compare authenticated stock402bytes, retained slice, actual REA provider bytes, all161 instruction starts against fresh Capstone Thumb decode, direct-call count24 and ELF subject hash. No provider run/harness was repeated. Discovery's GNU/Ablation direct-call equality adds corroboration. This remains an authored ELF envelope, not original firmware ELF metadata or reconstructed source build. Authored symbol/Thumb/PT_LOAD settings establish analysis context only. Missing external literals/callees prevent automatic type/global/source-identity conclusions.

For upcoming fixtures, stock token guard is byte equality: message event at+2 equals11 and CCB token byte+65 differs from message status byte+3. Connection ID is narrowed from message's16-bit field before CCB lookup; active CCB byte+61 must be nonzero. Matching token or another event dispatches to56EE62. “Stale” is source terminology for mismatched token; no temporal age, monotonic ordering or wraparound safety follows from byte comparison. Include equal/mismatch controls with byte0/255; do not compare full host integers against byte fields.

The mismatch branch initializes handler-ID byte at SP+16 and eventually loops: dequeue queue from literal537EE8 via4BF9EC; null ends; nonnull goes to4BF9B0 then repeats. Source drains the entire secCb.aesEncQueue, not a list filtered by connection or per-entry token. Fixtures should not invent filtering. Bind the literal, real queue-head/tail/link ABI, and allocated message-prefix offset before naming the ownership contract.

4BF9EC and4BF9B0 are thin wrappers, respectively calling538C4A and5304D4. Executing wrapper bytes with modeled underlying dequeue/free proves call routing only. For actual ownership evidence, execute the real underlying queue and pool-free provider instructions; seed valid allocated blocks/pool state and observe queue links/head/tail, free-list insertion, guards and exact pointer order. Empty queue should perform one dequeue and zero frees; two-entry FIFO should dequeue/free A then dequeue/free B then null, ending empty with both returned exactly once. Include matching-token two-entry control: no drain, unchanged queue, one dispatch boundary. Assert no incoming-message free unless a distinct actual path provides it.

CCB lookup, log policy/config/formatter/trace and downstream handler may be explicit hooks, but record their arguments/state and boundaries. Zero/suppressed logging is a fixture assumption, not observed device configuration. Dispatch hooks do not prove handler behavior. A free mock recording a pointer is not pool ownership/free-list proof; a dequeue mock is not actual queue ordering proof. No synchronous fixture proves interrupt delivery, concurrent AES producer behavior, UAF absence, live cryptographic behavior or global Cordio revision identity.
