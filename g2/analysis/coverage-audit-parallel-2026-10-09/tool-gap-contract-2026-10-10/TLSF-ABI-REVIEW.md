## Link and invariant boundaries

Source includes standard headers and tlsf.h; compiler-selected bit scans are GCC intrinsics or the portable implementation. Object undefined-symbol receipts must establish whether intrinsics lower to instructions or runtime helpers. Whole-object linkage may require assert-failure, printf/puts and memcpy. Stock references logger/assertion provider4733EE and copy439BE4; these are not interchangeable with ordinary libc just because normal fixtures do not call them. NDEBUG changes the contract. Configuration must be evidenced, not chosen to suppress inconvenient paths. Expected diagnostics/assertion branches should stop before the first unvalidated provider instruction.

Valid API pointers must be live owned blocks; double-free, interior/foreign pointers and malformed metadata are not ordinary equivalence fixtures. Free(NULL) is supported. malloc(0) returns NULL. realloc(NULL,n) routes to malloc; realloc(ptr,0) frees and returns NULL. Failed nonzero realloc retains original buffer and allocation; newly extended bytes are undefined. Compare retained old bytes, not an invented zero-filled extension. Shrink and adjacent-grow should preserve pointer and update split/coalescing metadata; moved growth exercises the copy provider.

Each free-list nonempty bit must match its actual list; links must be bidirectional, free blocks correctly bucketed, and adjacent free physical blocks coalesced. Sentinel size zero and prev-free state require checking after each sequence, not merely matching returned offsets. Include allocation sizes around 12/16, small-block boundary128 and FL/SL rounding transitions, plus split remainder around minimum payload+overhead16. A small allocation fixture alone cannot validate bit-scan/search classes.

Whole-arena equality requires identical initial sentinels and genuine same-address layout or typed pointer relocation. control_construct does not write the first two block-null words and allocation does not define unused payload/padding. These bytes should retain initial values; mismatching unspecified bytes must not be patched to force equality. If using different arena addresses, normalize only authenticated pointer fields, never arbitrary uint32 words that happen to resemble pointers. Matching offsets with corrupted flags/links is insufficient.

create_with_pool has no top-level guard against bytes smaller than control prefix, and add_pool subtracts8 before checking aligned capacity. Do not guess a safe recovery/status for unsigned underflow or pretend logger/assertion returned. Invalid alignment/minimum-pool inputs are separately bounded diagnostic tests, not a physical failure-safety claim.

The strongest next receipt is main initialization layout plus link-undefined-symbol closure for unchanged ARM32 source; then independent invariant walking alongside the owner's execution sequence. This audit did not compile or run a duplicate allocator harness. Source identity and geometry are strong; original-producing compiler/configuration, exact assertion/logging/copy providers, whole transitive graph and linked-byte equality remain unresolved. Zero coverage/admission changes.
