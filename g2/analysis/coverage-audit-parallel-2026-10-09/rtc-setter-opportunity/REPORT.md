# Finite untested opportunity: RTC time setter

Select the public Ambiq RTC time setter, not special-alarm timing. Four original extents independently hash-match the locked payload and Ghidra receipt: application DRV_RtcSetTime [47EE78,47EEFA), decimal-to-BCD [4D3A38,4D3A58), validator [4D3A58,4D3ACC), setter [4D3ADC,4D3B9A). [Static receipt](static-receipt.json) records bytes, hashes and callees. The public pinned am_hal_rtc.c and actual SDK 5.2 ZIP member have identical functional C after removal of comments/whitespace; missing source is not the boundary.

The stock caller constructs the same ten-word/40-byte ABI as am_hal_rtc_time_t: read-error +0, weekday +4, century +8, year +12, month +16, day +20, hour +24, minute +28, second +32, hundredths +36. Application year is relative to 2000; weekday helper is separate and should not be intercepted as if its behavior were already proven. Direct setter fixtures avoid that dependency. Stock setter calls validator and BCD conversion, which remain real original instructions in the proposed test.

A finite direct-setter comparison can use a valid seed and one invalid field at a time: hundredths 99/100, second 59/60, minute 59/60, hour 23/24, day 0/1/31/32, month 0/1/12/13, year 99/100/101, weekday 6/7. Century values 0/1/2 and read-error sentinels test ignored/masked fields. Stock and public validator accept year 100 and do not validate month-specific day counts (for example February 31); do not add calendar validation to the public contract. For year 100, uint8 BCD result is A0, a useful packing discriminator. Compare exact status and full ordered MMIO writes, including WRTC set, CTRLOW, CTRUP and WRTC clear. Invalid input should return failure with no register writes. Initialize registers with nonzero sentinels to expose preserved control bits and field masks.

Stock decompiled structure supports this hypothesis but is not a substitute for instruction checks: authenticate literal MMIO addresses, masks and BL targets before fixture execution. Getter, weekday helper, application logging, physical RTC counter advancement, alarm startup edges and oscillator timing are explicitly outside this finite setter goal.

Novelty check: bounded searches of analysis reports/results and emulator docs found no selected 4D3A58/4D3ADC original-versus-public-source execution receipt. Emulator docs/rtc-register-audit.md already compares register behavior to the HAL; docs/rtc-subsecond-alarm-boundary.md leaves F0/Fn encoding and stopped reconfiguration timing unresolved. This is not an exhaustive all-file absence proof. Check the owner's current assignment before execution, and stop if a sealed receipt already covers this exact contract. No duplicate recovered bytes or source-completeness advance is claimed by this selection.

This is outside closed DSP, LZ4, selected Nema, STRDIS/FDNB, touch constructor, delay arithmetic and Cordio short-header goals. No new source acquisition, registration, source edit, Git mutation or firmware execution was performed by this triage.
