A separate preseed-replay.py adds full65536-byte comparison immediately after each original/source operation and before that seeding. All74operations also pass this stronger check in an isolated /tmp/tlsf-independent-preseed directory. No new API cases or address-coverage count follows; this is additional verification of the same finite sequences.

Normal execution has no dependency-return hooks: original allocator instructions execute, and moved realloc executes actual original copy once. Source runs independently compiled genuine C copy once. Diagnostic/assertion providers stop if reached; they were not reached in these valid fixtures. Those stopping scaffolds satisfy this finite source-comparator link, not authentic production-runtime closure. All four candidate public-entry bodies differ stock; the result is behavioral equivalence in supplied sequences, not linked-byte equality, producing-version proof or original toolchain recreation.

The invariant walker independently checks physical block alignment/minimum/sentinel, predecessor flags/links, no adjacent free blocks, unique complete free-list membership, bucket placement and all bitmaps. Arena same-address equality additionally preserves all free-list pointer bytes/padding. It does not independently establish arbitrary memory reads are in bounds; harness guards writes, outer arenas and stack restoration. Header/control geometry and source configuration match the bounded ARM32 contract.

Current null-zero sequence ends there, so this does not invalidate observed behavior; any future reuse fixture must fix bookkeeping in a new harness. No union claim is admitted here.

Real copy was exercised only for the64-byte moved case, not all alignments/counts. These do not block acceptance of the stated74-operation contract but prohibit whole-TLSF closure. Verdict: supplied finite source/provider behavioral contract accepted; zero new-address/canonical admission advance. Owner evidence and prior seals remain unchanged.
