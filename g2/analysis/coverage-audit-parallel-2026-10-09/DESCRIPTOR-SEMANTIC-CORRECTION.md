# Additive descriptor semantic correction

New [CSKY-DESCRIPTOR-REFERENCES.md](../source-discovery-parallel-2026-10-09/CSKY-DESCRIPTOR-REFERENCES.md) distinguishes the existing E804 manual formula from the repository Ghidra model. Its section14.25 says BNEZAD decrements unconditionally, then branches when the resulting register is greater than zero. The Ghidra `32b_branch.sinc` uses nonzero. Therefore my earlier DESCRIPTOR-REVIEW's decoder corroboration must not be interpreted as general authoritative nonzero semantics. For initial positive8 this discrepancy does not alter the eight-slot loop; zero/negative/high-bit inputs need correct architecture-specific semantics and signedness confirmation.

E804 section14.93 corroborates low32 multiply-add; signed multiplication has the same low32 product. The official V2 ABI reference identifies preserved r4–r11/r16–r17/SP/LR and scratch r0–r3/r12–r13/r18–r25 with8-byte stack alignment. The initializer leaves preserved registers intact and only modifies listed scratch registers, supporting compatibility with that generic ABI and the observed caller. It does not authenticate exact target CK803 configuration or prove every E804 instruction variant exists on that target.

These are additive evidence qualifications, not edits to sealed packet or original review.
