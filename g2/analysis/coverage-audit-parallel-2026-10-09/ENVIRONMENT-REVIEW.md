# Configure environment review

Independent extraction from retained preprocessed files reproduces Configure SHA `191559a1fa56d41da22145ec4f352c70106b56033f9441d85c4b1e2471077658` for all three releases, bounds 8u and 3u, and 27 matching noncompiler input hashes against prior 13.3. [ENVIRONMENT-VERIFICATION.json](ENVIRONMENT-VERIFICATION.json) records those checks. No build was repeated.

The expanded body contains direct register/config/context accesses, arithmetic and loops without external provider calls; no generated cycfg appears in the consumed dependency records. No-call evidence is stronger from inspection of the expanded definition than from environment.py's `Cy_*` call regex alone, which is not a universal call detector. The report correctly keeps runtime configuration and producing-layout identity separate.

Comparing full normalized translation units is a meaningful bounded sanity check because identical function text alone does not include typedef widths, register volatility, structure packing, attributes, or pragmas declared outside it. This audit removed line directives and normalized whitespace across complete `.i` files: 11.3 and 12.2 match one another; 10.3 differs. Compiler-owned header differences were already documented, so a whole-file mismatch is not itself a new causative discriminator. A focused comparison of the declarations actually used by Configure, plus any active packing/optimization pragmas, could establish whether those differences matter. It requires static inspection only, not another compilation matrix. No original-producing or retained 13.3 full `.i` file was compared here.

Supported remaining hypotheses are: genuinely different producing Configure source/revision, different effective declarations/attributes or producer flags/whole-program context, and compiler lowering outside the tested candidates/environment. Their presence as possibilities is not positive evidence that any occurred. LTO is a speculative alternative, not established by this standalone experiment. Generated cycfg is not a demonstrated immediate cause for this body's layout difference. Header/source changes between the three tested public builds are excluded for the 27 pinned noncompiler files; compiler header and original-producer environments remain separate.

Authentic PDL history comparison is the next source-led discriminator, with declaration comparison as a small static cross-check. An identical-source duplicate build, arbitrary flag sweep or manual byte fitting would not improve attribution. The environment report's bounded conclusion is supported; unique producing-source/compiler attribution remains open.
