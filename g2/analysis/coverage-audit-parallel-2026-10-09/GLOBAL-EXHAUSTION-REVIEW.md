# Scope audit: source exhaustion is bounded, not global

The evidence supports audio/UART/power static exhaustion at its specified boundaries and closure of the selected54-entry PDL comparator census (4952bytes). It does not support global firmware source exhaustion. [Roadmap](../../../docs/roadmap.md) requires six payloads/33images and separate classification, reviewed-function, exact-match and source-produced metrics. [Workflow state](../../workflow/state.json) remains P2_EXECUTING; G2/G3and implementation/source/equality gates have not run. This audit performs no new build, admission or canonical edit.

## Highest-value concrete available-source gaps

1. **Touch startup and runtime providers outside the census.** [Next-dependency ledger](../source-dependency-next-ledger-2026-10-09/REPORT.md) identifies constructor walker0xA9E4(56historical bytes), exit0xA9AC(historical54-byte extent overlaps memset0xA9D4), halt0xAA40and init stub0xAA44. Existing newlib/libgloss/crt source families and exact Arm release metadata provide a focused route: authenticate the relevant provider source/member, resolve extent/attribution and initializer/finalizer-array references, then compare. These are untested static leads, not physical-device blockers. Do not promote the overlapping exit extent or introduce handwritten startup stubs. Newly finalized [signed division](../touch-libgcc14-signed-2026-10-09/REPORT.md) and [memset](../touch-newlib14-memset-2026-10-09/REPORT.md) remain independent-review work; their reported468/16bytes cannot yet be folded into audited dependency totals. They do not expand54selected PDL entries.

2. **C-SKY board structure and image-profile binding.** [Constraints](../source-discovery-parallel-2026-10-09/FINAL-CONSTRAINTS.md) binds getter0x10203004to0x200269A4while historical storage uses0x100269A4; initializer0x10203024reads halfword+0x20and gain bits6–9. KWS/AIoT source and240candidate configuration bytes are available. Recover image-bound alias/storage mapping and authentic structure/packing/enum offsets before testing PDM/I2SIN/SADC source discrimination. No hardware observation is needed just to test static offset/layout consistency. Physical active configuration still needs separate evidence.

3. **C-SKY higher-level interfaces and reachability.** [Indexed accessor](../csky-indexed-word-accessor-2026-10-09/pseudocode.md), [offset256 accessor](../csky-offset256-accessor-2026-10-09/pseudocode.md), [descriptor](../csky-descriptor-initializer-2026-10-09/pseudocode.md) have bounded reviewed bytes, not complete caller-purpose/global-type attribution. Direct-call census does not exclude indirect callers. Descriptor144row/12slot stride and two written words do not identify a complete source structure. Follow caller use, literal roots and existing NationalChip headers to constrain actual buffer/control contracts. Available source searches have no exact descriptor binding yet; absence of that match is neither public-source impossibility nor proof that physical traces are the only next step. Coordinator adoption is administrative reconciliation, not a new source-recovery experiment or permission to change counters here.

4. **Source-branch constraints are not exact producer attribution.** Five PLL offsets and active VAD diagnostic callsites constrain KWS-like lineage. The LOGFBANK channel4/+8/threshold25branch is shared and cannot discriminate KWSfromAIoT. Remaining CFG/reachability, authentic configuration and source-history comparisons can narrow attribution using already acquired sources; no arbitrary compiler sweep is justified. [C-SKY toolchain correction](../csky-toolchain-correction-2026-10-09/REPORT.md) establishes opcode-field/feature eligibility, not a unique SDK/compiler/core. Physical CK804identity and producing toolchain remain unknown. Preserve the positive-BNEZAD correction and vendor four-byte alignment qualification; the old nonzero/eight-byte statements cannot be exported unqualified.

5. **Per-image coverage and ARC startup need explicit mapping.** embARC OSPis an acquired architecture comparator, not attributed source. BLE application record maps to0x00302400and vector slot0points outside that application range; available vector slots and local body bytes allow bounded ARC interrupt/provider comparisons where resident application code exists. The external startup address's absent ROM/factory content is a genuine artifact boundary, but it does not make in-image ARC bodies or all other32images exhausted. Global code/data, nested-image, indirect-dispatch and provider coverage must be reconciled against current owned campaign scopes. Historical workflow assignment totals do not enumerate every live task contract.

## Genuine physical/private boundaries

Live NVIC/PendSV/task selection, actual callback/vector contents, calibrated INFO1/clock data, physical GPIO/UART/power/bus outcomes and timing are not supplied by synthetic fixtures. Exact private Ambiq/application/NemaGFX/controller source, IARruntime/configuration, resident ROM/factory bytes absent from OTA, and private packaging/signing inputs need their own authenticated evidence. These are distinct from available-source static leads above. A generic private-source category must not be used to classify every unmatched public family without image-bound negative evidence.

No claim here restarts implementation or a firmware campaign. Pseudocode completeness, source completeness and whole-bundle equality stay separate. Closed local comparisons do not imply all public inference is exhausted; several named static provider/interface leads remain useful.
