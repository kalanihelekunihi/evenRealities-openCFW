The recovered state ABI uses four modules, a `0x8D0`-byte stride, and SRAM

null output handles, and already-allocated state. A successful call writes

clock-frequency and TCB fields, selects clock source 7, sets the XIP-off
minimum delay to 8, and publishes the state handle. Host tests cover each
success and rejection path and verify non-mutation on failure.
