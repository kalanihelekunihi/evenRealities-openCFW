## Conclusion and metric

**21.32% of the current core-source EVENOTA package is source-built or
deterministically generated. 12.59% is actual production source ownership.**
Another 0.62% has touch/case source candidates that are not production-routed;
78.06% remains retained stock or external-provider content in this partition.
**None of the six whole payload components is fully source-complete.**

These are byte-ownership percentages, not estimates of engineering effort,
semantic understanding, functional parity, time remaining, or hardware readiness.
Generated branches, padding, headers and checksums are counted separately from
compiled source. Retained bytes can include understood assets, tables and
unreachable tails; they are not necessarily wholly mysterious. Classifying a
retained range does not reverse its implementation. A raw machine-code transcript
inside a C file is not credited as semantic source reconstruction.

## Source-count inflation and verification gaps

The current Apollo configuration contains 5,448 AM helper entries, totaling
1,001,924 configured bytes, in 182 helper files. They are selected only for the
literal `g2` profile. The supported/default `apple-clang` and `linux-clang` paths
do not select them. Inspection found extensive `.inst.n` raw instruction
transcriptions in those files. They are excluded from this assessment's source
credit: their existence and compilability do not establish semantic reversal.

The raw-encoding auditor's current regex recognizes `.byte`, `.short`, `.hword`
and `.word`, but not `.inst`; its Apollo source scan also starts from the
top-level `sources` list. Therefore its clean result alone cannot certify all
configured helper source. The current release audit reports 182 source-metadata
errors, beginning with SHA mismatches for these helper files.

The historical 165/198 implemented-capability count was not used as a current
overall completion percentage. It has a different denominator and the ledger
predates the present code. A fresh full hardware/feature parity assessment was
not performed.
