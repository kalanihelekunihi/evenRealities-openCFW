# P3 worker: global completeness and freeze review

Independently examine the complete candidate corpus for the locked official
artifact. Require six component submissions and their independent reviews.
Run the approved global validators and inspect their denominator/evidence;
do not trust a hand-entered percentage, old function count or state flag.

Verify package and payload interval conservation, all nested images and address
spaces, code/data dispositions, vectors/entries, callback and indirect transfer
rules, cross-image/external interfaces, split/shared bodies and every executable
range's reviewed pseudocode. Reconcile unknown, partial, failed and unsupported
counts to actual records. Unknown semantics or unexplained executable regions
block the gate, including in a component considered “done” historically.

Verify the candidate manifest covers raw and reviewed artifacts, mappings,
data/types/interfaces, tool receipts and reviews. Check all file hashes and the
durable storage location. Confirm no missing or mutable dependency hides outside
the snapshot. Review all six components together; do not waive one so another
can start C.

Return a proposed freeze report with per-component summaries, validator receipts,
manifest hash, exact blockers and a `pass` or `blocked` recommendation. Only the
coordinator may publish the immutable G3 receipt after validating this report.
Do not create C modules, headers, implementation tasks or source code in this
assignment. If blocked, identify the smallest analysis repairs and evidence
needed to review the corpus again.
