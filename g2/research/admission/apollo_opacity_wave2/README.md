# Apollo opacity wave 2 boundary

This research-only record closes the seven unresolved functions and 8,072
official opaque bytes in the complete one-hop call community rooted at
`0x005156B8`. Each body and its official envelope is SHA-pinned. The root's
66-byte and `0x005639E8`'s 30-byte decoded-body shortfalls remain inside their
authenticated envelopes and are not silently presented as source.

The bodies implement vector-path, geometry, state, and command-record
operations. That behavior and their location near authenticated Nema entries
make NemaGFX/NemaVG relevant provider context, but do not prove an exact
upstream function identity. The checked-in Nema provenance resolves eleven
stock symbols and none is one of these seven. Its public Apollo5 archive is a
GCC compatibility artifact while these stock bodies use IAR code generation;
the original IAR archive/private source state is unavailable.

Every row therefore remains `typed-external-provider-unavailable`, with no
claimed upstream function, source body, or license. The Nema package's retained
licenses apply only if an authenticated Nema source/artifact is separately
admitted; they are not assigned speculatively to these boundaries. Callers
must retain stock or fail closed. Nothing here is routed into production.
