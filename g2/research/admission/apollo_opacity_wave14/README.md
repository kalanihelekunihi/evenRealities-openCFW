# Apollo opacity wave 14

Wave 14 is a research-only FreeType CFF source closure rooted at
`cff_slot_load` (`0x005AC66E`). Five residual functions account for 2,006
official opaque bytes and map to the authenticated FreeType 2.9.1 sources
under the FreeType Project License.

All static terminal relations are prior admitted source. Six dynamic provider
interfaces are typed separately: four registered FreeType module interfaces
and two optional client incremental interfaces. A dynamic interface is not a
license or target-identity claim about an unknown client implementation.

Production routing remains excluded pending exact feature macros, object ABI,
and reviewed dual-profile Cortex-M55 codegen, relocation, link, and placement
proof. No aggregate or production artifact consumes this directory.
