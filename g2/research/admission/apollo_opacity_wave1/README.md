# Apollo opacity wave 1 boundary

This research-only record closes a ten-function, 9,002-byte call-connected
community rooted at `0x005202EC`. It provides no implementation and makes no
upstream-source claim. The authenticated evidence proves exact body/envelope
identity and root-to-leaf calls, while the provider remains unavailable.

The likely graphics/vector-command context is only a family description. It
is not sufficient to claim LVGL, NemaGFX, NemaVG, or an Ambiq implementation:
the checked-in source snapshots contain no exact definition, the prior
peripheral-register census explicitly rejects the root's apparent register
literal as a constant collision, and the large body crosses first-party,
LVGL, and rejected-envelope call boundaries.

Every row therefore uses `typed-external-provider-unavailable`. A caller must
fail closed or retain the stock boundary until a separately authenticated
source/provider and ABI are admitted. Nothing here is production-routed.
