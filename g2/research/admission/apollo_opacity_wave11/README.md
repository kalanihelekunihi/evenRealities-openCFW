# Apollo opacity wave 11

This research-only wave closes the complete residual static call graph rooted at `0x005AF88C`. Positive source evidence identifies `cff_face_init` and 41 other bodies from the authenticated FreeType 2.9.1 (`VER-2-9-1`) snapshot. The remaining positive-byte body is the linked `strncmp` runtime implementation at `0x0044B610`; it stays a SHA-pinned, typed IAR DLIB boundary because the proprietary runtime source and exact configuration are unavailable.

The 43 selected bodies account for 10,098 official opaque bytes. Each body has one contiguous range, so there are no hidden interior islands. `shared_data.tsv` exhaustively records all 34 direct data cells surfaced by the decompiler; those cells are physical evidence and add no function-envelope bytes. `reconciled_frontier.tsv` closes every terminal static edge without double counting earlier waves.

The upstream sources remain under the FreeType Project License in `g2/third_party/freetype/LICENSE`. This admission does not rewrite those sources as MIT code.

Production routing remains excluded. Source identity does not prove the original feature macros, ABI, IAR library model, optimization/LTO choices, Cortex-M55 code generation, relocation, link order, or placement. A production overlay would require reviewed dual-profile build receipts and byte/relocation-equivalent placement proof.
