Readable native reconstructions with explicit original-function dependencies. They are not production firmware modules. Analysis, proven behaviors and limits (`pre-consolidation:g2/analysis/audio-info-memory-providers-2026-10-08/REPORT.md`). Four suites pass1,182 comparisons on one final artifact. Pinned public SDK is an interpretation lead; exact stock differences are preserved.

The MCU/SRAM memory-config helpers that were here (`memory.c`, stock 0x47F204 and 0x47F46A) are now upstream SDK 5.0.0 `am_hal_pwrctrl.c`; see `g2/evidence/main-hal-upstream-review.json`.
