# Reconstructed radio pin117 consumer

This module integrates the source-backed GPIO/PRIMASK foundations with the stock radio counter/event consumer. `opencfw_radio_gpio_register` publishes channel0 pin117, the reconstructed callback and NULL argument. `GPIO0_607F_IRQHandler` retains the seven-bank raw snapshot, reads bank3, clears its pending mask before dispatch, and ignores helper return codes as stock does. The callback increments the fixed RAM counter modulo2^32 and submits event1 to the byte-sized handler ID.

These are reconstructed C functions, not unchanged SDK consumer source. GPIO leaf source is separately attributed to Ambiq SDK5.1.0, Git commit5efc0228528a8adce5eae0d226fac85d2551eb3b (see authoritative `../ambiq_gpio/SOURCE_PROVENANCE.json` for full exact identity). No full boot replacement is provided. Link an actual `opencfw_radio_scheduler_event` provider when integrating beyond the simulator; the included empty provider is a synthetic verification boundary and must not be used as a production scheduler.

Build: `make -C g2 radio-gpio-simulator`. Compare: `make -C g2 radio-gpio-simulator-test RADIO_GPIO_SIM_REPORT=build/foundation/radio-gpio-simulator/comparison-new.json` (new output path required). Installed OpenCFW Python/Unicorn needs native execution on this host. ARM Cortex-M4 compatible Thumb2 compilation is used for the M55 consumer's instruction subset; this is not a board target change.

Privileged execution, mapped RAM/registers, initialized scheduler ID, valid callback tables and serialized publication/dispatch are caller preconditions. Registration writes handler before argument with no critical section. The specialized setup publishes the callback, enables GPIO117, writes IRQ59 priority4 and NVIC ISER bit27. Disable masks only GPIO117. No ownership transfer/free, cancellation, physical delivery, pad setup, or concurrency safety is implied. See `../../../analysis/radio-gpio-consumer-2026-10-05/REPORT.md` for evidence and limits.
