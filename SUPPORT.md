# Support

Community support is provided through GitHub issues. Search existing issues and
the target documentation before filing a new one, then include:

- the exact commit and host operating system;
- the command that failed and its complete software-only error output;
- the selected toolchain profile and compiler version; and
- whether official inputs were locally present, without attaching or quoting
  proprietary payloads.

Start with [docs/README.md](docs/README.md) and [docs/build.md](docs/build.md).
The project can help diagnose source, tooling, and reproducibility problems. It
cannot provide official firmware, signing keys, proprietary services,
redistribution permission, warranties, or guaranteed hardware recovery.

Do not use a support issue for sensitive vulnerabilities or personal data; use
[SECURITY.md](SECURITY.md). Directed hardware testing is outside the current
software-development phase unless separately coordinated.
